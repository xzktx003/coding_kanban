## 四条可复现路径与修复

### 普通消息反复持久化审查历史

`AgentMessageItem` 完成后向review store投影finding，即使普通回复的finding为空。旧store保存每个空数组；即使set callback返回原state，Zustand persist仍序列化并同步写整张map。1000条普通消息产生1000个owner、1000次写盘、累计25,887,990字符；随后100次同值投影没有UI通知，却仍序列化5,185,200字符。

现在set前判等；无旧finding的空投影直接返回，清空真实旧finding时删除对应item/空owner。重复虚拟挂载不写盘。恢复旧设备存储时一次过滤明确的空数组，不逐条触发persist；非空finding、用户评论/草稿、scope及未知形状保留，初始化不写盘，下次真实变更保存紧凑map。修复后1000次普通投影及100次重复均0次写盘；旧1000空owner恢复过滤和评论保护先红后绿。

### 导航订阅了所有正文引用

`useFollowedSessionStates` 原订阅所有关注线程events数组；任意正文更新会重算菜单和运行摘要，即使状态和问题数量不变。100次正文快照更新导致101次渲染。现只订阅根卡片的待答异步问题数量，仍保留权限/审批、原生提问、确认/跳过回执、未读、执行状态和子Agent元数据订阅；相同问题数不触发导航重渲染。相同负载现仅1次渲染；问题出现、原生答复/确认/跳过和新轮次退休仍更新。既有WeakMap问题索引保留，未声称每次selector完全不扫描。

### 大代码块自动高亮阻塞主线程

8MiB正文预算不能限制正则扫描几十种语言及生成大量DOM节点的成本。真实浏览器用原高亮注册表处理约90089字符无语言代码，耗时1612.9/1343.6ms，定时输入延迟1623.4/1398.2ms；已知TypeScript同大小产生11200个span。缓存超字符预算时立即淘汰，又会重复高亮。

现有语言代码超过16Ki字符、无语言代码超过4Ki字符，在加载语言、序列化cache key和语法计算之前返回完整安全转义文本；不截断源码、复制内容不变，正常小代码仍保持原生grammar/alias。相同浏览器负载处理0.9–3.4ms、输入定时器3–49.5ms、span为零，正文逐字符一致。这不是所有Markdown解析或所有小输入正则的执行时间保证。

### 帧暂停时增量队列无界

旧 `pendingDeltas` 只限单item文本；暂停rAF后5000个不同item、每项约4KiB只登记一帧，恢复时一次flush约41MB估算数据。交错summary相同key合并还会重排文本。

现队列最多128项／1MiB估算，触顶先处理最老小批，每批最多32项；普通帧每批后检查4ms预算，把余量留到下一帧。仅相邻同身份合并，保留thread/method/turn/item/summaryIndex/contentIndex；完成/卸载先清空本线程待处理，休眠立即释放。压力小批发布后立即运行既有governor，防止积累被搬到store；不停止任务或丢掉正常delta。

一条不可缩小的原生身份自身超1MiB时立即处理，不把它留在暂停帧队列；store治理前可能短暂超过8MiB一个小批，不能宣称每次subscriber均严格在8MiB内。治理也保留既有用户主动阅读额度，不能把短测外推到所有阅读窗口。

真实React hook＋产品store的浏览器用例暂停rAF，交错注入5000条agent/summaryText delta：最大待处理118项／967836正文估算bytes，最大单次store调用2项；events＋streaming峰8438268bytes，5000项全部按序送达，完成正文保留、帧回调清零。JS used heap约6.67→12.72MB、renderer RSS约115.88→133.52MB，仅短时观测，无强制GC。该测试按字符串长度计算的pending bytes不包含元数据，完整entry预算另外由单测覆盖。
