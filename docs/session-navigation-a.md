# 会话导航 A 与深浅色

用户确认的评审基线：[设计稿](designs/navigation-v1/design-review.md)。本次仅改变会话模式的导航呈现，沿用现有会话、关注集合、输入目标和运行层。

## 布局与操作

- 侧栏默认 288px；桌面会话行 36px，手机 44px。项目按细分隔线、缩进与留白分组；项目操作在悬停/聚焦或触屏时显示。
- 标题 13px，默认单行；标题可聚焦，tooltip 显示完整名称和 Agent 信息。Agent 图标常显且带可访问名称，不以颜色区分归属。
- 时间沿用各适配器原有语义；悬停、聚焦、菜单展开时在同一固定槽显示操作入口，文字不位移。重命名/归档/删除仍复用原有能力和确认流程。
- 分页使用双下箭头，aria-label 和 tooltip 保留“加载更多”；加载中禁用，失败显示文字并允许重试。Claude 已加载/受控数据先本地展开，请求按项目代次隔离。
- 后续项目归属方案已替换初版合并栏：每个标签/卡片使用 48px 会话名与项目名两级身份块；网格/列表删除重复标签条。布局和工具进入全局顶栏。详见 [会话项目归属](session-project-context.md)。
- 每条会话的项目名都是详情入口，提供完整执行目录、侧栏定位和复制，不隐式切换输入目标。项目行始终显示；同名目录消歧，工作树区分，未知目录明确提示。
- 窄屏将布局和项目工具收进全局“更多”；桌面顶栏直接显示布局与 Git。手机保留顶栏侧栏展开、主题及更多按钮，各窗口组保留自己的标签导航。

## 主题

右上角太阳表示切换浅色，月亮表示切换深色。操作写入现有 `kanban.session.theme-storage`；首次沿用原设置，包括 system，手动切换后固定为另一种模式。设置页仍能选择跟随系统。

`ThemeProvider` 在 SessionWorkbench 外层覆盖导航、连接页、App 及其 portal；嵌套 Provider 复用上层，原独立 App 入口仍可使用。主题只修改 `.session-mode` 的类、变量和 color-scheme，不改终端模式根，不重建 Agent、标签、草稿、终端或 VS Code iframe。

`session-navigation.css` 仅使用 `.session-mode` 作用域。默认主题提供深浅两套语义颜色；其他 accent 继续沿用原主题。状态颜色在浅色下调整为可读深色。

## 最小验收

- 单测：三类 Agent 归属、键盘选择与操作菜单隔离、删除确认、分页成功/失败/重复点击/迟到响应、项目菜单、合并栏、主题持久化与主题作用域。
- 浏览器：长标题 focus 提示、深浅色 portal、跨项目切换、标签拖动/关闭/分屏恢复、刷新后主题与草稿、VS Code iframe 持续挂载；覆盖 1440/1024/900/768/390/320px。
- `pnpm check` 验证共享包、后端、前端类型与构建；测试使用拦截 API 的隔离会话，不向真实 Agent 发送任务。

局域网开发服务沿用 `.env` 配置和 `pnpm dev:restart`。本轮已有服务可热更新，无需重启运行层。实际结果与访问地址见本轮验收记录。

本轮已完成的检查、历史失败与限制见 [实施验收](designs/navigation-v1/implementation-acceptance.md)。

## 项目侧栏开关（2026-10-08）

桌面只在顶栏最左侧保留一个项目列表开关：展开时显示“收起项目列表”，收起时显示“展开项目列表”，图标、提示与 `aria-expanded` 同步，按钮位置及 DOM 不变。侧栏搜索行移除重复收起入口。键盘关闭后焦点保留在顶栏开关，方便直接再次展开。

手机使用模态抽屉，顶栏会被遮住，因此抽屉内部保留关闭按钮，并支持 Escape 和关闭后回到打开按钮。功能页上的项目入口仍按已有离开保护返回聊天并展开项目，不直接修改隐藏侧栏。

验证：相关组件测试先复现三个失败断言后转绿；浏览器检查同位置开关、键盘焦点、草稿、主题、刷新和 320/390px 抽屉。局域网验收地址 `https://10.30.0.24:8484/?mode=session`（HTTPS，8484），使用隔离 API，不启动或停止 Agent。

本次结果：18 项相关组件测试、4 项浏览器场景及前端 TypeScript 检查通过。浏览器验收同时更新了旧测试对桌面工具入口位置的断言，工具入口本身未改动。
