# 会话交互间歇卡顿复验（2026-10-29）

用户反馈持续工作时点击、输入和输出间歇停顿，偶尔必须刷新。基线是 `da92e625`。本轮闭合四条可复现的放大路径；原现场的持续卡死未完整复现，不能据此宣称长期内存和所有卡死均已根治。

## 因果证据与修复

| 路径 | 修改前 | 修改后及保护边界 |
| --- | --- | --- |

| 长对话导航 | 600 条用户提示词在十次无关 reasoning 更新中重复生成 6,600 个标签，切换还挂载 600 个按钮 | 稳定用户投影与标记；超过 128 条使用固定 10px 行、最多 640px 视口与 overscan，保留首尾和当前焦点。真实 1,000 条导航测试 DOM 不超过 100，所有提示词仍可滚动、键盘和鼠标到达 |

长导航另发现并修复两个真实输入问题：pointerdown 立即捕获鼠标会吞掉按钮单击，现仅跨标记拖动时捕获；焦点按 row ID 保留，前缀回收/插入不会把焦点移给另一条提示词。拖动后的抑制不能吞掉下一次 Enter/Space。预览继续使用最新助手内容。

用户明确要求的历史阅读功能保持：主动向上翻页期间仍使用既有 120,000 事件/256MiB 兼容额度；本轮结束的是返回最新后遗留的额度，不把所有阅读恢复硬改回 8MiB。这些都是显示正文估算预算，不是浏览器标签页 RSS 上限。

## 浏览器复验

隔离前端绑定 `0.0.0.0`，实际 LAN 入口 **HTTP `http://10.30.0.28:35605`，端口 35605**。使用真实应用、HTTP/EventSource、真实输入/点击/滚轮与 API fixture；未向正式 Codex 发送任务、停止 Agent 或刷新来释放内存。长测前后私有源码及共享编译产物 1,990 文件 SHA-256 清单一致，不受根目录构建/HMR 干扰。

`session-live-interaction-performance.spec.ts` 的短测（500 轮、2,002 SSE 帧）通过；50.291 秒中 150 个按键到下一 RAF 的 p95 为 55.7ms，最大 183.9ms，计入输入排队后最大 184.3ms。五次实际 tab 点击到目标选中/草稿显示约 102–237ms。两个会话各预载 600 条用户提示词及助手内容，持续交错 reasoning、回复与输入，检查目标和草稿。

显式 `SESSION_INTERACTION_CYCLES=6000` 的十分钟测试完整跑完 **601.631 秒**，持续 25,202 帧（含工具开始/结束元数据），150 次按键、五次切换、四轮附件/会话菜单开关；无 pageerror，没有持续挂起或刷新。按键到下一 RAF p95 **45ms**、最大 **83.9ms**，计入原始输入时间排队后最大 **139.4ms**；实际点击到目标选中/编辑器草稿 **86–132.3ms**，到 RAF **89.7–148.2ms**。菜单关闭后 body 指针可用且编辑器可继续输入。

**十分钟总验收仍为红灯**：自动化整步点击/断言有一次切换 **578ms**，超过原 `<500ms`，未放宽阈值或将其删除。该次页面内点击到选中为 116.3ms、到 RAF 132.1ms；整步还包含驱动往返和断言等待，不能把 578ms 全部归为页面绘制，也不能把页面内较低数值当作整步通过。

自然回收采样中 heap 约 70.2→145.1MiB，renderer RSS 411.1→796.8MiB，中间多次升降；无强制 GC。记录的是自有浏览器 renderer 的 RSS，不是 private/PSS；十分钟响应性复验不能替代标准三十分钟内存测试，既有长期 RSS 红灯仍有效。由于正常后台正文回收/恢复和预算生效，导航数量并非始终维持初始 600 条；不能声称全程等重的满历史负载。

真实滚轮分页四项通过，新增一项先红后绿：加载旧页、禁用阅读位置 Storage.setItem、滚到最新，旧实现 pin 保留，修复后清空；正常历史正文与分页仍可读取。真实长导航单项通过：首/中/尾滚动、100 次 Tab、焦点跨窗口和前缀变化、单击、拖动、Enter/Space。
