# 工作台界面与交互统一

本轮以真实局域网页面截图检查布局，再用同一页面上的隔离数据复现长名称、多个会话、分屏、手机抽屉和错误状态。保留现有石墨色工作区、暖色强调及可选主题，统一控件语义、间距和状态层级。

## 导航与项目

- `WorkbenchModeSwitch` 由会话顶栏和终端顶栏共同使用，左侧「会话」、右侧「终端」。点击轨道反转模式，点击文字选择对应模式，拖动越过中点后松手切换；取消手势不切换，拖动后的 click 不会再次反转。支持方向键和原生按钮的 Enter/Space，减少动态效果设置会关闭滑动动画。
- 模式切换和功能导航以空间、背景与分隔线区分。进入定时任务、设置等页面时仍属于会话模式，点击「会话」返回对话。手机通过「更多」访问定时任务、工具、用量、设置，保留状态摘要；ACP 手机标题栏保留新聊天入口。
- Logo 保持完整比例与独立空间，修正原先用 20–26px 容器裁切约 100px 图片的规则。
- `ProjectNavigationButton` 在桌面显示文件夹、项目名与侧栏动作图标，在手机显示文件夹与「项目」；两者都明确控制项目与会话列表。长路径省略展示，完整路径保留在提示中，不把它当作会话标签。
- 项目列表、历史项目、排序和项目操作统一名称与图标。会话卡片复用可读 Agent 标签，标签与卡片关闭都表述为「关闭标签」，提示后台任务继续运行。

## 连续操作与响应式

模式切换沿用现有工作区挂载结构，保留草稿、会话集合和布局。首次进入终端模式时才加载终端应用；已访问的终端应用继续挂载，但在会话模式隐藏期间暂停完整 xterm 和终端连接，返回时按受限历史回放恢复。会话模式工具终端尚无断线回放，仍保留原连接和输出；已打开的 VS Code iframe 继续保留编辑状态。键盘或指针从模式控件切换后，焦点转到新模式的推杆；手机项目抽屉关闭后回到入口。`SheetContent` 和已有 Dialog 使用相同的焦点恢复原则，隐藏模式不夺取焦点。

工作台根节点跟随当前主题的正文与背景颜色，避免浅色主题继承深色文字而失去对比度。卡片的手动宽度受到所在区域宽度约束，避免桌面保存的大尺寸在手机上越界。窄分屏使用容器查询调整标题层级，代码保持区域内横向滚动；卡片底栏文字提高可读性，等待状态使用中文和语义色。加载占位与工具栏使用一致的节奏，窗口尺寸调整句柄提供可访问名称。手机消息队列限制为不超过 96px 或视口高度的 12%，长队列内部滚动，保留正文阅读空间。

终端的更新提示嵌入工具栏状态区，并在工具栏折叠时继续可见；恢复结果仍使用原有通知条。修正悬浮更新指示器固定在左上角遮挡 Logo 的问题。更新、拉取和重试仍由原有显式操作驱动。

侧栏 Context 使用模块内的 Vite `hot.data` 保留引用，避免刷新组件模块后，已挂载 Provider 和新 Consumer 引用不同 Context，造成页面加载失败。生产环境与不同模块之间的 Context 仍各自隔离，不增加全局业务状态。

## 任务与会话连续性

真实流程检查同时补上以下边界，避免入口调整引入隐式中断：

- 更换连接中的 ACP Agent、新建会话需要中断运行任务、失败后需要关闭服务重新连接时，先显示说明后果的确认框。取消保留原任务；确认按原连接和会话校验归属，过期确认不能中断后来选择的任务。
- 隐藏或关闭终端工具页保留已经打开的终端子树，只有显式关闭终端窗口才结束它。开发热更新不停止后台终端。
- 终端启动结果晚于窗口关闭时，仅清理此次启动返回的终端，不向已关闭窗口发送预设命令。StrictMode 替换窗口实例时允许当前实例重新连接。
- ACP 项目、会话历史加载以选择版本与连接身份校验结果；迟到响应不能覆盖更新的选择。

这些修复沿用现有 API，不改变 Agent 协议，也不通过截图测试操作真实 Agent。确认框在桌面和 320px 手机视口均通过实际浏览器点击取消与确认验收。
