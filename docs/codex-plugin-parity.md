# Codex VS Code 插件模式对照清单

## 目标与基线

目标是在 Coding Kanban 的 Codex 模式中保留官方插件的聊天与编辑器交互，并把看板独有的窗口组、公共输入等能力接到原生窗口上。官方 VSIX 与其 Webview 不打补丁；看板自有代码负责宿主、代理、窗口编排和边界适配。云任务按用户确认延期，其余插件能力默认仍在本阶段范围内。遇到宿主能力限制时，先记录具体行为、原因和证据，不能用静态字符串或注册成功代替实际验收。

当前唯一对照基准是本地未修改 VSIX `26.51007.21434`：`third_party/openai.chatgpt-26.51007.21434-linux-x64.vsix`，SHA-256 `75cee7497cf38c721cfeaa7383b579537b4e4439086f996258705de5da03ad56`；解包目录为 `third_party/openai.chatgpt-26.51007.21434-linux-x64/extension`。REA 对原包的库存与解包证据分别为 `ev_4cd0a7d74c9d2d7f6b1fa84231c554229b4a33bfcac2d96672dfecdc8e921866`、`ev_8957db3bff263fcc5b937196aa94368fea1b42d882d6a57c2a9a40bcff98ed73`。本文件后续矩阵是从 `26.51002.51308` 阶段保留的历史状态快照；该版本的 REA 静态证据 `ev_317195dffb3c170c95d427bd9e95346ee4fa49ab6b0702294eb8dcda1628ed86` 不能证明当前版本行为。当前逐项完成状态以[会话模式完整目标审计](designs/session-render-alignment/current-goal-audit-20261027.md)及其链接的同版行为/浏览器证据为准。

状态含义：

- **已验收**：隔离真实浏览器中完成操作，保存截图，并有对应回归。
- **部分验收**：只覆盖了列出的路径；未列出的行为仍需验证。
- **待验收**：尚无足以支持行为一致的浏览器证据。
- **延期**：用户明确要求留到下一阶段。

## 每项功能的交付证据

每项行为变化先写能复现缺口的失败用例，再修改实现；同步维护 `docs/func_list.md`，bug 修复追加 `docs/debug_list.md`，需要沉淀时更新 `memories/repo/debug_list.md`。浏览器验收使用隔离 Codex HOME、隔离项目和真实可见操作；截图与测试结果记录在本文件对应行或关联验收文档。真实账号／MCP 场景必须使用用户授权的连接副本，不提交凭证、会话正文或浏览器状态。新聊天恢复的浏览器状态截图暂存于被忽略的 `.dev-runtime/native-integration/`；它证明登录页与双面板基线，不代替刷新恢复实测。

最终闭合前运行相关 Vitest、宿主／适配器 Node 测试、`pnpm check` 和 `pnpm test`，并完成同版本 UI 逐项截图复核。若宿主 `EMFILE` 阻塞全量测试，可在无网络隔离容器中以只读源码和隔离缓存复跑完整套件；须同时记录宿主限制与隔离运行结果，不能以专项测试代替全量通过。
