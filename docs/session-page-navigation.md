# 会话功能页与返回导航

定时任务、工具与技能、用量、设置采用完整功能页，共用固定的“返回会话”标题条。桌面顶栏另有独立“聊天”入口；手机在返回按钮旁显示功能页选择器。会话/终端开关仅负责切换工作模式，不能代替页面返回。

## 导航和生命周期

- `SessionTopNavigation` 提供入口；`SessionSecondaryHeader` 提供统一返回和手机页面选择。标题条位于内容滚动区、Suspense 和功能页错误边界之外，加载慢或单页崩溃不会带走返回入口。
- `AppLayout` 保持原 AgentView、项目侧栏、分屏和 RightPanel 的组件位置；功能页打开时隐藏并设为 inert。返回使用原有选中会话和布局，不创建会话，不启动/停止 Agent，不复活已关闭标签。
- 页面切换使用 `useLayoutStore.setView`。`SessionPageNavigation` 挂载期间同步 `view` URL 参数及浏览器历史，保留其他 query、hash 和 mode；页面名使用白名单。刷新恢复当前功能页；后退/前进恢复相应页面。
- 没有已有会话时，“返回会话”进入聊天空态。明确选择其他会话时，沿用现有选择动作，不强行跳回旧目标。
- 进入功能页聚焦标题，返回优先恢复之前的有效焦点，否则聚焦选中会话标签或项目入口。粗指针设备返回时不主动聚焦文本输入框。页面内模态的 Esc 由其自身处理，不新增全局 Esc 返回操作。
- VS Code iframe 和终端工具树保持挂载；切换模式仍沿用 WorkbenchShell 的保活机制。

## 未保存表单

`useSessionLeaveGuard` 登记当前显式保存表单的 dirty/saving 状态；`requestSessionNavigation` 统一协调页面离开。普通聊天草稿由原有会话草稿机制持久化，不触发此确认。

- 未保存：提供“继续编辑 / 放弃更改并离开”。取消保留页面和正文；明确放弃后执行原导航动作。
- 保存中：禁止放弃并离开，等待保存结果；失败仍保留未保存状态。保存响应只确认提交时的内容，不覆盖保存期间的新输入。
- 浏览器后退被取消时恢复原 URL/history 位置，保留前进能力；刷新/关闭页面使用浏览器原生未保存提示。
- 已接入：Codex 配置、个性化指令、Claude 环境设置、定时任务编辑、MCP 新增/编辑和 Bot JSON 配置、用量的模型计价。设置内部分类切换和插件内部页面切换也复用离开检查。
- 自动保存偏好不增加重复确认。模型计价在数字输入变化时立即标记编辑，不能等到失焦才保护，以覆盖浏览器后退及未填完的数值。

## 验收入口

局域网 HTTPS 地址：`https://10.30.0.24:8484/?mode=session`，端口 8484 来自本地配置；源码不固定主机/端口。

红绿灯与浏览器验收记录见 [导航验收](designs/session-return-v1/acceptance.md)。浏览器用独立上下文和隔离 API fixture 验证写入/错误场景，正式服务只做只读页面检查，不运行真实定时任务、修改 Agent 配置或重启 Agent。
