# 聚焦返回与显示页面

## 目标

1. 从宫格一键回到离开前的聚焦分屏。
2. 聚焦视图可以有多套显示页面，用鼠标切换；每页各自记住布局、排列和格子里的 session。

## 返回上次

- 宫格视图顶栏放「返回上次」，与聚焦视图「返回宫格」同一视觉位置：顶栏右侧操作区。
- 仅当本次浏览中离开过聚焦视图、且当时的输入 session 仍存在时显示。
- 点击后进入聚焦视图，恢复离开时的输入 session。布局和格子由显示页面状态恢复，不另存一份。
- `Alt+Q` 仍只返回宫格。

## 显示页面

- 初始只有一页，名称「默认」。点「＋」追加的页从「页面 1」起编号。任何一页都可以改名和关闭，只剩最后一页时不能关闭。
- 「屏幕布局」菜单在布局选项之后按创建顺序列出全部显示页面。当前页为选中项，位置不因选中而改变。点击其它页切换，点击「新建页面」追加一页，双击非默认页改名，非默认页可在此关闭。菜单内的切换、新建、改名、关闭与顶栏标签做同一件事；切换、新建、关闭完成后关闭菜单。
- 页签始终显示，按创建顺序渲染。当前页高亮但不移动到最前。点击未选中的页签切换；再点击当前页签在其下方弹出小气泡，可改名、切换自由排列或分组排列、切换屏幕布局、关闭该页。点气泡外或按 Esc 关闭。
- 改名在小气泡内完成，名称去首尾空白后不能为空，也不能与其它页重名。关闭只删除该页记忆，不关闭 session。关闭当前页时切到前一页。
- 每页保存：屏幕布局、窗口排列（自由排列或分组 id）、分组内顺序、格子 session、当前输入格子、关闭的空格子。
- 同一 session 可出现在多个页面。
- 当前页的布局和格子改动只写入当前页。
- 非当前页不挂真实终端。切换后只挂当前页可见格子里的终端，沿用现有按窗格加载。
- 状态写入本机 `localStorage`，键 `terminal-monitor-pages-v1`。旧的 `terminal-monitor-workspace-v1` 在首次读取时迁入「默认」页。
- 已删除的 session 从各页格子中清除，格子留空。

## 不做

- 不在页面间移动 session 的独占归属。
- 不为离开的页面保持真实终端连接。
