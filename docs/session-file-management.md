# 会话模式文件管理

会话模式右侧“文件”工具保留原来的文件树、多个编辑标签和未保存草稿，并提供与终端模式一致的常用文件操作。入口在桌面工作区工具栏，手机从工具菜单进入。

## 常用操作

- 文件树初始指向当前项目；可通过“文件浏览路径”和返回上级浏览本机其他目录。浏览位置不改变会话工作目录或注册项目；切换项目回到新项目，已打开文件及草稿保留。点击文件夹选中该目录，新建和上传作用于它；选中文件时作用于其父目录，没有选择时作用于当前浏览目录。
- 顶部操作栏使用中文文字显示上传、下载、复制绝对路径、复制相对路径和刷新，手机窄屏可以换行。文件树行末菜单与桌面右键菜单提供相同的文件操作，目录支持下载 ZIP。
- 支持一次选择多个文件，或把文件拖入文件工具区上传；显示传输进度，可以取消。已有同名文件仍需选择跳过、改名或确认覆盖，覆盖沿用磁盘版本校验。拖入文件夹会明确提示当前只支持文件，不会把目录当作零字节文件上传。
- 单文件直接下载，目录打包为 ZIP。内容由浏览器原生下载处理，前端不通过 `response.blob()` 缓存整份文件或 ZIP；下载失败不会覆盖当前编辑页面。
- 复制路径复用终端模式剪贴板工具，支持 HTTPS 剪贴板和 HTTP 局域网／权限拒绝时的兼容路径。项目根目录的相对路径为 `.`；失败显示可重试错误。

## 调整文件树与预览宽度

桌面文件树与文件预览之间的竖线支持左右拖动，也可以 Tab 聚焦后用左右方向键调整，Home／End 调到边界。文件树默认占 35%，可调整到 20%～65%，预览至少保留 35%。宽度只在本设备保存，隐藏再显示、切换文件和刷新页面时恢复；存储不可用时本页仍可拖动，无效保存值回退默认。

复用已有分栏组件，不新增全局拖动监听、轮询或依赖。预览面板位置固定，隐藏树不卸载编辑器；移动端继续使用文件树抽屉，不显示桌面分隔条。回归为 `FilesPanel.usability.test.tsx`、`session-files-split.spec.ts`，并保留文件草稿安全与文件夹展开验收。

## 文件树后台刷新

同一项目的新建、删除和手动刷新保留已挂载的文件树、滚动容器、焦点及展开目录，读取完成后原位更新。初次加载和切换项目才使用整区加载提示；切换项目立即清除旧项目可操作的文件行。根目录或已展开目录读取失败保留最近一次成功快照，在树底部显示可重试错误，不压缩树高度。旧快照不代表文件仍存在，后端仍校验每次文件操作。

回归：`features/files/explorer/useFileTree.test.tsx` 覆盖 create/remove、展开目录失败、重试、scrollTop/焦点及换项目隔离；浏览器布局入口见 [会话布局稳定性](session-layout-stability.md)。

## 接口与资源边界

原 `workspace-files` 服务继续校验项目注册和项目根目录；项目外文件通过单独的 `local-files` 接口解析、读写、传输及操作，项目执行环境接口不因此扩大。访问者可操作看板运行账号有权限访问的本机文件，包含未注册项目；这不改变系统账户权限，也不会把目录加入项目列表。接口沿用部署现有的访问控制，不自行增加登录：未部署认证时，任何能连接服务的设备都可能访问这些文件；HTTPS 本身不提供用户认证。下载仍先获取元数据，再由浏览器传输；项目及本机图片预览沿用现有配对 token 传输方式。

目录 ZIP 使用既有 archiver 依赖流式生成，跳过软链接，不通过链接读取所选目录外的目标，并拒绝特殊文件。打包条目和目录深度有上限（10000 项／64 层），避免无限枚举；取消或响应关闭释放源流和打开的文件。没有新增依赖或整份 ZIP 缓存。单个上传文件沿用后端 64 MiB 限制，顺序发送避免并发保存多份正文；取消中止请求，不把已经上传成功的文件回滚或删除。

此能力用于本机文件，不扩展为终端 SSH 文件浏览器；保留编辑草稿、保存版本检查、回收站及恢复规则。文本编辑沿用 4 MiB、UTF-8 和普通文件限制；实际读取也受字节上限约束，避免文件增长或 `/proc` 等零长度元数据绕过限制。图片、PDF、Office 沿用既有预览能力。Git 元数据修改、带硬链接文件覆盖、文件树操作直接穿过符号链接以及应用回收站自身操作仍受现有保护。下载信息检查与实际下载之间仍会重新检查目标；文件被外部进程修改、删除或权限变化时下载可能失败。

## 对话文件链接与符号链接解析

普通 Markdown 文件链接、原生文件引用、工具资源链接和文件预览内的本地链接，使用同一打开流程：项目内引用优先经 `workspace-files/resolve`；项目外路径或未注册的符号链接目标经 `local-files/resolve` 获取真实路径，再通过本机文件接口打开。相对路径以原消息所属项目解析，不使用点击时另一个会话的工作目录；行号、列号和引用行范围保留。打开外部文件不会切换会话或输入目标。

典型场景为 `xh2modelzoo/xhquant -> ../xhquanttool/xhquant`。两个项目均已注册时，引用中的别名路径会打开 `xhquanttool` 下的真实文件，读取、保存和版本检查使用真实 root/path；不更改原会话项目、不创建临时别名标签。较晚返回的旧点击或读取失败不会覆盖后来选中的文件。

解析接口只返回路径元数据，不读取正文、不注册项目。本机路径可跨项目，解析后以真实路径读取和保存；断链、循环链接、特殊文件或系统权限不足仍报错。操作执行前重新检查路径，文件读取保留 `O_NOFOLLOW`，目录 ZIP 保留软链接跳过规则。仍保留大小、编码、版本和草稿保护，不引入全文缓存或轮询。浏览器地址栏目录输入仅接受本机绝对路径；切换时的迟到响应不能覆盖新项目位置。

预览组件始终订阅文件 root 与当前项目 root，不能在 `??` 分支内调用 Hook；文件树有选择回调时由回调负责打开，不能先用旧 `setSelectedFilePath` 暴露未解析路径。
