# 会话模式文件管理

会话模式右侧“文件”工具保留原来的文件树、多个编辑标签和未保存草稿，并提供与终端模式一致的常用文件操作。入口在桌面工作区工具栏，手机从工具菜单进入。

## 常用操作

- 点击文件夹选中该目录；新建文件、新建文件夹和上传都会作用于这个目录。选中文件时，新建和上传作用于它的父目录；没有选择时使用当前项目根目录。切换项目不会沿用前一个项目的目标。
- 顶部操作栏使用中文文字显示上传、下载、复制绝对路径、复制相对路径和刷新，手机窄屏可以换行。文件树行末菜单与桌面右键菜单提供相同的文件操作，目录支持下载 ZIP。
- 支持一次选择多个文件，或把文件拖入文件工具区上传；显示传输进度，可以取消。已有同名文件仍需选择跳过、改名或确认覆盖，覆盖沿用磁盘版本校验。拖入文件夹会明确提示当前只支持文件，不会把目录当作零字节文件上传。
- 单文件直接下载，目录打包为 ZIP。内容由浏览器原生下载处理，前端不通过 `response.blob()` 缓存整份文件或 ZIP；下载失败不会覆盖当前编辑页面。
- 复制路径复用终端模式剪贴板工具，支持 HTTPS 剪贴板和 HTTP 局域网／权限拒绝时的兼容路径。项目根目录的相对路径为 `.`；失败显示可重试错误。

## 接口与资源边界

复用项目限定的 `workspace-files` 服务及注册根目录验证，不使用终端的任意路径接口替代权限校验。新增 `POST /api/session/workspace-files/download-info` 返回验证后的 `{path, filename}`；前端随后通过 `GET /api/session/workspace-files/download?root=...&path=...` 触发浏览器下载。原 POST 下载和图片预览保留。配对设备沿用现有 URL token 机制，下载接口仍验证根目录及路径。

目录 ZIP 使用既有 archiver 依赖流式生成，跳过软链接，不读取项目外目标，拒绝特殊文件。打包条目和目录深度有上限（10000 项／64 层），避免无限枚举；取消或响应关闭释放源流和打开的文件。没有新增依赖或整份 ZIP 缓存。单个上传文件沿用后端 64 MiB 限制，顺序发送避免并发保存多份正文；取消中止请求，不把已经上传成功的文件回滚或删除。

此能力用于当前会话项目的本机工作区，不扩展为终端 SSH 文件浏览器，也不改变编辑草稿、保存版本检查、回收站及恢复规则。下载信息检查与实际下载之间仍会重新检查目标；文件被外部进程修改、删除或权限变化时下载可能失败。
