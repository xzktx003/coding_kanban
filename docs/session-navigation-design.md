# 会话模式紧凑导航

本轮按用户确认的手机/桌面草图实现：小品牌标志与会话功能合并为一行，项目入口固定在会话标签最左侧，关注状态易于查看，低频工具收进菜单。当前联调前端为 HTTPS 局域网地址 `https://10.30.0.24:8484/?mode=session`；地址取决于本地 `.env`，源码没有固定主机或端口。

## 导航职责

- `WorkbenchShell` 保留终端模式原有顶栏。会话模式由 `SessionWorkbench` 的 `SessionTopNavigation` 显示一行全局导航，通过回调切换工作模式。两种模式保持各自挂载状态。
- 顶栏常驻小 Logo、会话返回入口、模式下拉、定时任务、关注状态和更多。手机将工具与技能、用量、设置、导入和布局/辅助工具放进更多；桌面宽度足够时显示次要页面入口和运行数量。
- 手机标签栏按“项目 → 关注标签 → 全部关注会话与窗口组 → 新会话”排列。窗口组选择与全部关注列表共用一个下拉；标签改名/关闭保留选中标签的操作菜单。项目与新会话仍可直接点到。
- 桌面项目侧栏与各窗口组的标签保留，中央上方提供项目入口及紧凑项目工具。自由分屏、网格、列表共用关注集合；切换不会重新创建 Agent 或取消后台任务。
- VS Code Web 入口使用 16px 图标。桌面按钮约 28px，手机项目抽屉内按钮保留 44px 触控区域；打开方式仍是新浏览器标签页。
- 输入区域始终显示发送目标，包括项目名称、会话名称和 Agent；新聊天也显示当前项目和 Agent。项目抽屉的浏览与已有会话的选择不混用。

## 关注状态

`useFollowedSessionStates` 只读取共享关注集合及本浏览器已有 Agent 状态，不隐式收集服务器上的其他会话，也不为状态查询启动 Agent。

- Codex 待确认来自运行状态旗标以及审批、权限、用户提问、elicitation 请求。Claude 待确认来自未解决的权限请求。
- 状态优先级为待确认、运行、失败、新回复、已完成/空闲；缺少状态数据时显示“状态待同步”。断连时显示“正在重连”，不把未知数据计为确定的零。
- 手机顶部优先显示待确认数量；没有待确认且状态已同步时显示关注数量。运行情况在展开列表中显示；桌面同时显示运行数量。
- 状态列表包含 Agent、项目与窗口组信息。选择一项使用统一会话选择流程，同步当前会话、项目与发送目标；Codex 待确认的主动定位会跳到线程末尾的请求区，不执行审批。
- 每个分屏审批卡按自己的 thread ID 选择请求，避免把全局第一条审批显示到其他会话中。
- 关注同步失败的文字说明放在关注下拉内，避免手机标签行被错误文字挤占；顶栏同时显示尚未同步的状态。

## 验证

- `useFollowedSessionStates.test.tsx`：关注范围、请求优先级、状态变化、未知和断线。
- `SessionTopNavigation.test.tsx`：合并导航、页面选择、空关注、未同步与重连反馈。
- `ApprovalItem.session.test.tsx`：多会话审批卡隔离及正确的响应 request ID；实现前失败，实现后通过。
- `session-navigation-design.spec.ts`：320/390/768/1440px 单行顶栏、无整页横向溢出、待确认定位、全部关注入口、项目抽屉小号 VS Code、模式切换与草稿、模拟键盘尺寸、发送目标及新聊天。
- `session-split.spec.ts`：嵌套三屏、组切换、移动/收拢、刷新恢复与输入目标。相同的 390×900 场景中正文区域约 682px，上一版约 639px。
- 模态隔离及次要页面浏览器回归覆盖切模式后释放焦点锁、恢复草稿、手机菜单、错误重试和返回聊天。

### 全量会话单测的未通过项

最终全量运行记录为 300 通过、6 失败；其中回滚草稿用例在工作区后续更新后单独复查通过，剩余五项 ACP/终端生命周期红灯已在 `session-ux-lifecycle-plan.md` 中记录：ACP 迟到历史响应、新会话/更换 Agent 隐式停止、关闭终端工具树和迟到终端启动。本轮导航及审批隔离、启动与草稿用例均通过；不能把该全量运行记录称为全部通过。

验收浏览器集合为 8 项全部通过，覆盖导航、分屏、20 个关注标签、次要页面及三种宽度的模态隔离。直接相关单测集合 52 项通过；额外补查启动、草稿、Claude 监听、审批和回滚的 20 项也通过（与前者存在重叠）。`pnpm check` 通过，最终前端类型检查通过。

启动验证还覆盖草稿兼容层的初始化顺序：模块导入时不读取其他未初始化 store，App/消费者挂载后恢复草稿并共享订阅；卸载时释放订阅。`input-facades.bootstrap.test.ts` 与 `sessionDrafts.regression.test.ts` 检查启动、跨会话草稿、迟到提交和旧草稿迁移。
