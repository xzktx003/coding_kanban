# 会话标签与关注集合

## 已确认的交互

标签栏是当前服务实例内跨设备共享的关注集合，跨项目共用，支持 Codex 和 Claude；Codex 为主要验收对象。ACP 保留现有单会话体验。左侧置顶仍用于长期收藏，与标签集合独立。

- 从左侧、历史管理、置顶或深链接打开会话，追加到标签栏右侧并激活。重复打开只激活已有标签，不增加副本、不改变顺序。新聊天在实际创建会话后加入集合。
- 点击标签同步切换 Agent、会话和工作目录。顶部标签、窗口选中态、公共输入框目标保持一致。网格与列表在输入框上方显示“发送到”。
- 拖动标签改变顺序；网格和列表使用相同集合、相同顺序。单会话显示当前标签，列表只展开选中项，网格同时展开各项。
- 关闭标签、关闭网格窗口或从任务工具面板移除，均只移出关注集合，不中断任务、不删除历史、不删除 worktree。关闭选中项后优先选右邻，没有则选左邻；最后一个关闭后显示新聊天入口。
- 关闭后台标签不改变当前输入目标；后台完成、待确认等事件保持原有左侧状态提示，不自动重新加入标签。
- 左右键切换标签，Home/End 跳到首尾，Delete 关闭当前聚焦标签，Alt+Shift+左右键移动标签。快捷键只作用于有焦点的标签，不注册全局浏览器关闭快捷键。
- 标签多时横向滚动；窗口多时内容区向下滚动。选中标签在容器尺寸变化后滚动到可见位置。

## 状态与恢复

`useAgentCenterStore` 的 `cards` 是唯一关注集合；身份由 `kind + id` 组成。新增、移除、排序均通过该 store 完成，布局不维护第二份会话集合。

`useSessionTabActions` 统一导航和关闭语义，`useRestoreSessionTabs` 仅在工作区首次挂载时恢复选中项。恢复操作不订阅后台活动来自动添加标签。Codex 网格恢复历史不依次激活每个窗口，历史请求仍由现有服务合并和处理迟到响应。

Codex 标签状态由 `followedSessionStatusSync` 在会话服务就绪后主动恢复，独立于当前选中会话和侧栏列表。同步使用已有 `thread/list` 只读查询，跨项目、跨模型提供方分页查找关注会话，必要时查询归档集合；只填充关注项的 `threadStatusMap`，不替换侧栏历史列表、不切换输入目标、不 resume 后台 Agent。首次连接、SSE 重连、关注成员变化、重新联网和页面返回前台均触发状态快照同步；后续变化继续由现有事件桥处理。请求串行合并，失败保留已知状态并在 5 秒后重试；查询期间到达的状态/轮次事件优先于迟到快照。离线或卸载时取消请求和订阅。Claude/ACP 状态沿用各自事件链路。

共享集合由 Node 网关的 `GET/POST /api/session/tabs` 管理，持久化到 `SESSION_DATA_HOME/followed-sessions.json`（保留上一版 `.bak` 备份）（未配置时沿用现有会话数据目录）。仅同步 Codex/Claude 的关注成员、显示元数据和排列顺序。选中 Agent/会话、输入草稿、阅读位置、单会话/网格/列表布局、窗口尺寸均留在设备端；手机切换标签不切换电脑对话。

localStorage 的 `kanban.session.agent-center-store` v5 保留集合缓存、本地选中项、布局和待提交操作。首次初始化由最先连接设备的现有关注集合建立；此后设备读取服务器集合，旧缓存不覆盖服务器。首次迁移到共享集合不会自动合并后来设备的旧标签，用户可从会话列表重新加入。

客户端立即显示本地操作，约 50ms 后提交，通常每 2 秒拉取远端变更；重新联网或页面回到前台立即同步。失败显示“同步待重试”，待提交操作保存在浏览器，断线刷新后继续提交。服务端按客户端单调序号幂等处理添加、更新、移除、移动，逐项合并并发操作；同一项的冲突按服务器接收顺序决定。重试不重新添加已被另一个设备移除的会话，元数据更新也不会复活已移除项。单批最多 100 个操作、集合最多 500 个会话。

服务端串行处理、临时文件写入后原子替换，写入成功才发布新版本；文件读取失败不会静默清空集合。接口只接受集合操作，不接受选中项、布局、存储路径或命令参数。同步不依赖 Rust 运行层更新。

另一设备移除本机正在阅读的会话时，该标签从共享集合消失，但本机保留当前对话和滚动位置，并显示“当前会话未关注”；在网格/列表中也保留该本地窗口直到本机切换或关闭。远端添加、排序、移除都不调用本机导航。

旧版 v4 的卡片由浏览历史隐式积累，升级时不整体迁入关注集合。热更新或深链接已有当前会话时保留该会话；旧版没有持久化当前会话 ID，完整重载且无当前会话时从空集合开始。升级不删除后台会话或历史。

### 手机自由分屏导航

手机保留本设备的桌面分屏树，但仅显示当前窗口组；组选择器合并进该组标签栏，不额外占一行。原桌面会话工具栏在手机自由分屏中隐藏，布局、会话/项目与右侧工具通过“会话工具”菜单访问。标签选中后提供操作菜单，关闭仍只取消关注，不停止后台任务。窄屏输入工具行保持单行，发送目标提示保留。

验证：`tests/e2e/session-split.spec.ts` 覆盖 390px/320px 手机宽度、正文可视高度、整页无横向溢出、切组后的发送目标及桌面嵌套分屏恢复。联调地址为当前 `.env` 配置的 HTTPS 局域网前端 `https://10.30.0.24:8484/?mode=session`；源码未固定该地址。

### 固定名称与各会话草稿

标签名来自独立会话名称状态，已有名称固定，只有全新会话用首条消息初始化，手动改名优先。继续发送不再把本次消息写入标签名称。旧版临时预览首次加载真实名称或首条历史消息后校正一次。

公共输入框按当前 Agent/session 展示独立文字和附件；关闭标签不删除草稿。草稿保持设备本地，支持刷新和浏览器重开，上传中断可重试；发送期间新增内容与其他会话草稿不受迟到结果影响。结构、迁移及验收见 [会话草稿](session-drafts.md)。
