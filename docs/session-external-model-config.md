# 外部 Codex 模型配置与新聊天

2026-11-09。适用于会话模式，自有 Codex 模型选择器；独立 Codex 模式保持原生宿主行为。

新设备的新聊天默认选择“跟随 Codex 配置”。旧设备只要保存过模型或提供商，缺少新意图标记时保守保留为手动模式。每个字段仍单独存储，不整表回写；已有线程继续使用独立线程设置，不因 Magpie 切换而更改。

只读 `POST /api/codex/model/config/read` 接受可选绝对 `cwd`，调用实际连接的 `config/read`（`includeLayers:false`），仅返回 `status:ready`、`model`、`modelProvider`、`reasoningEffort`。不返回 base URL、账号、密钥、原始配置或日志，不 acquire/resume，不发送模型任务。目录最多4096字符，模型1024、提供商128、强度64；控制字符拒绝。权限配置公开投影保持独立，不增加权限授予能力。

菜单和延迟加载触发器显示“跟随配置 · 模型”。成功读取到 `model: null` 时明确显示“原生默认”，加载、读取失败和未选项目也分别显示准确状态，避免把已完成读取留在“读取中…”。进入可见的新聊天、打开跟随菜单及显式刷新时读取配置；没有后台轮询，已有线程打开菜单不强制重载目录。配置模型独立展示，不要求出现在官方目录中，可“固定使用”成为手动选择。2026-11-09后续补齐：新聊天菜单打开时通过网关只读兼容接口 `/api/session/model-catalog/magpie` 读取已配置的本机Magpie `/models`，独立分组列出，选择时同时保存magpie提供商和精确模型ID。无需替换旧运行服务。仅允许配置中magpie的HTTP loopback地址，不接受客户端地址、不发送凭据、不跟随重定向；5秒截止、1MiB响应、最多2048项，每项1024字符。失败不伪装空目录，菜单提示不可用。无配置时为空；远程或带认证网关尚不支持。

2026-11-10 补充：通用模型目录的模型、提供商、其他模型和推荐模型读取共享 15 秒截止并可取消。显式刷新会取消较旧的在途读取；同时到达且新读取尚未开始的刷新合并，读取开始后的新刷新安排下一次读取。迟到的旧响应不能覆盖新结果。超时保留已接受的模型和提供商数据，显示错误及重试入口；原生目录读取失败时仍禁止基于旧目录选择模型，未取得目录时显示“模型目录不可用”，不误报用量限制。提供商单独刷新也有截止并保留旧数据。所有操作均为只读，不发送或重试会话任务。

发送手势捕获新聊天意图并立即启动5秒截止的配置读取；只有已选工作目录时才读取，缺少目录时优先提示“请先选择项目目录”，不发送空路径。异步准备和后续UI选择不能替换捕获结果，读取失败在创建前拒绝并保留草稿。原有运行代次和账号检查继续生效。读取到的模型/提供商/强度作为本次显式参数，null表示原生默认，不能编造openai默认。配置读取与实际创建之间没有原生跨客户端CAS；上游地址、凭据或账号在这期间变化不能由模型标识保证不变。自定义工作树的项目配置仍须按其最终原生语义判断，不能把源目录配置显示当作最终路径全部配置证明。

旧运行服务不存在该端点时，404/405/501明确提示“当前运行服务不支持读取模型配置”，不改读磁盘冒充有效配置，不启动私有app-server，不自动重启服务。当前现场旧runtime需要在安全维护窗口显式更新；构建新产物不代表运行中的服务已支持。接口报告的是原生配置读取结果，不证明配置文件与启动快照一致，也不证明流量或计费上游。当前界面不声称检测到磁盘配置未应用。
