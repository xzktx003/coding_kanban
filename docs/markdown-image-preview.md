# 终端模式 Markdown 图片预览

## 路径与依赖

`MarkdownImage` 在图片接近视口时通过 `POST /api/fs/markdown-image` 读取本地或 SSH 图片，再由浏览器解码。沿用 AbortController、对象 URL 回收和 16 MiB 单图上限；无需安装图片转换器。

标准 `./`、`../` 引用相对文档所在目录，`/` 引用保持既有根目录规则。新增的飞书导出语法 `@./` 从文档目录逐层向上查找，直到请求中已有的 `rootPath` 为止，优先使用最近祖先中的匹配。它不改变普通相对路径的读取规则，也不修改原文。多个祖先同名时，要指定确定文件可改用标准相对路径。

## 安全边界

- 文档、每个候选路径以及最终真实图片路径必须位于允许根目录；查找不得扩大根目录。
- 仅文件不存在或父组件不是目录时尝试下一个祖先；权限错误与符号链接越界直接失败，不能隐藏错误后继续查找。
- 本地 `ENOENT` / `ENOTDIR` 和 SSH SFTP 状态 2 表示可继续查找；SSH 身份、文件元数据和流读取复用原服务。
- URL 编码、查询和 fragment 使用原解析规则；控制字符、反斜杠、URI scheme 和越界路径仍然拒绝。
- 图片类型取后端 MIME 表，浏览器负责实际解码；补齐 AVIF/BMP/ICO 后仍不执行格式转换。

预览响应以可选 `resourceRootPath` 返回文档所在的最近 Git 项目目录，通过向上检查 `.git` 目录/普通文件识别，支持嵌套项目与 worktree，不执行 Git 命令或读取 `.git` 内容。只有 Markdown 查询这个元数据；SSH 在原 SFTP 通道内完成，权限错误立即结束探测。桌面分段窗口保留这个字段，桌面/手机共用根目录选择：文档项目优先，其次包含文档的已配置范围，最后文档目录。浏览外部项目不能继续使用不相关的终端工作目录，也不能扩大到全盘。

## 验证

`apps/server/src/routes/filesystem.test.ts` 覆盖嵌套导出目录、最近祖先优先、越界拒绝、图片格式、本地/SSH 流式读取和大小限制；`file-system-utils.test.ts` 覆盖查找终点、普通路径不回退、权限错误、真实路径越界、SFTP 缺失状态及编码文件名。LocalFsService 测试验证嵌套 worktree 目录；前端测试验证项目切换与分段元数据。`tests/e2e/file-browser.spec.ts` 的跨项目图片用例从原会话打开其他项目的文档，验证标准相对路径与飞书引用均解码成功。

本机实际浏览器验收地址：`https://10.30.0.22:8484`。从 coding_kanban 会话浏览论文时，红灯为五个请求带原会话目录并返回 400；修复后五个请求带论文项目目录并返回 200，五个 `<img>` 的 `naturalWidth` 均大于零。单独验证接口不能替代浏览器根目录与解码链路的验证。
