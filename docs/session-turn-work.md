# Codex 按轮工作摘要与用时

会话模式在每轮用户消息之后、过程消息之前显示统一的工作摘要。运行中显示“已处理 2分钟 46秒”，每秒更新；完成后显示可展开的“用时 10分钟 59秒”，默认收起中间过程，最终报告在摘要下独立显示。只改变展示，不改变执行、审批、原始历史或发送目标。

## 原生依据

对照仓库保存的 `third_party/openai.chatgpt-26.51002.51308-win32-arm64.vsix`，工作元数据投影 `Wgt` 和摘要组件 `GLi` 分别采用 `localConversation.workingFor` 与 `localConversation.workedFor.v2`；运行和完成共享同一工作摘要入口，后者分隔过程与最终报告。展开后的工具继续使用现有原生活动分组。原包提取和对照产物保留在被忽略的 `.dev-runtime/session-render-alignment/review/`。

## 数据与展示边界

- 每个 thread/turn 单独生成摘要。运行用时来自该轮原生开始时间，当前轮缺失时采用已有会话计时状态；完成用时优先采用原生 `durationMs`，其次采用可验证的开始/完成时间差。无可靠用时显示“工作过程”，不虚构零秒。已确认完成后，迟到的开始事件/运行快照不能恢复计时。
- 过程包含中间回复、公开 reasoning 摘要、计划、工具活动、公开 Hook 和子 Agent 过程记录；明确的 `final_answer` 保留在外。旧历史缺少 phase 时，仅在原生明确完成的轮中将最后一条无 phase 的普通回复作为最终报告。缺少轮次状态的旧事件保留原展示。
- 失败/中断提示、警告与交互问题保持可见；审批与权限请求继续使用独立入口，重连提示不被摘要覆盖。私有推理正文仍不展示。
- 运行中过程展开；完成后过程默认折叠。正在阅读过程时保留当前阅读锚点；点击展开/收起固定摘要所在位置，搜索/消息跳转会展开包含目标的轮次。折叠不缩小既有搜索与导出范围：仍从未折叠的已加载内容投影，继续遵守原生正文搜索排除即时 commentary、计划与公开摘要的规则。
- 本页会话重新挂载时保留展开选择；刷新后恢复默认折叠。隐藏窗口不持续运行计时器，恢复显示后按开始时间重新计算。切换主题使用已有 Codex 字体和颜色变量，计时文字使用等宽数字。
