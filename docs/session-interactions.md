# 会话模式提示与输入交互

## 视觉规则

沿用深色工作台和系统字体，采用低面积的语义色。空闲和已读会话不显示圆点；运行中保留青绿色旋转图标，标题栏附短文字。仅完成未读、等待处理、失败在名称右侧显示蓝色、琥珀色、红色提示，并提供文字说明。未读网格卡片使用细蓝色边框和轻微标题底色，当前选择仍使用原有选择描边；等待与失败优先于未读。遵循减少动画偏好。

## 完成与阅读

`useSessionAttentionStore` 按 `kind:id` 保存最近完成的回复身份及已读身份，ACP 的 id 包含 agentId。Codex 只接入实时成功的 `turn/completed`，Claude 只接入成功的实时 `result`，ACP 只在 prompt 返回 `end_turn` 后记录。历史读取、错误、取消和重复通知不生成新的未读提醒。

每个会话最多保留 32 条身份，全局最多 512 个会话。本地持久化保留刷新后的状态；同浏览器其他标签通过 storage 事件合并完成和已读集合，旧回执不能清除新回复。不同设备的已读状态不共享。

最新内容末端通过 IntersectionObserver 检测可见性，结合会话视图、浏览器前台焦点与当前选中窗口，持续可见 250ms 后确认该条回复已读。仅出现在网格中、浏览旧消息或隐藏工作台不算已读；关闭侧栏不会清除未读。点击卡片正文同步选择该卡片和输入目标。

## 侧栏

桌面折叠后留一个边缘入口，悬停 150ms 浮出原侧栏，覆盖内容而不增加布局占位。离开 250ms 收回，指针仍在入口/侧栏、菜单打开或键盘焦点仍在侧栏时保持；Esc 关闭菜单后可继续关闭预览。固定展开恢复原有持久布局，悬浮状态不持久化。手机保持点击抽屉。隐藏 session 模式不响应全局侧栏快捷键，快捷键也不接管编辑框。

## 图片输入

Codex 的 Lexical 输入框、Claude 和 ACP 的 textarea 共用图片草稿与上传条。图片粘贴在 capture 阶段转成附件；纯文本粘贴交给原编辑器。缩略图可预览、移除，上传中及失败时不允许发送半条消息，失败可重试；附件与异步上传结果始终归属粘贴时的会话。现有文件选择菜单仍复用同一附件条。

上传复用 `/api/session/files/upload`，单文件上限 10MB。Codex 使用 localImage，Claude 使用 image_paths，支持仅图片消息。ACP 新增可选 image_paths，运行服务仅接受当前 `SESSION_DATA_HOME/uploads` 中解析后的普通文件，拒绝目录外路径及外指向符号链接，识别 PNG/JPEG/GIF/WebP 字节签名。每次最多 8 张、总计 32MB；JSON-RPC 请求使用原生 `image { mimeType, data }` 块，并要求初始化协商 image 能力。图片历史也保留为图片内容。

运行服务 `/health` 声明 `capabilities.acpImages`。旧实例未声明时，客户端明确拒绝图片发送并保留草稿。新二进制已构建。按用户确认，保留当前正式运行实例，等下一次完整重启项目及会话运行服务时更新；普通 Node/Vite 热重启仍复用旧实例。不得为了启用图片隐式终止正在运行的 Agent。

## 验收

- 单测：完成/重放/旧回执/刷新、前台阅读归属、常态无圆点与运行转圈、侧栏预览、文本粘贴、上传阻塞/失败重试/晚返回归属、旧 ACP 实例拒绝。
- 浏览器：`tests/e2e/session-interactions.spec.ts` 覆盖运行图标、未读网格、悬浮布局与菜单、三类输入框图片请求及桌面/手机；`session-copy.spec.ts` 验证原复制修复仍成立。
- Rust：原生图片内容、协商后的 JSON-RPC 请求，以及上传目录/格式/符号链接校验；隔离运行服务配本地确定性 Agent 实测 HTTP 图片发送，不调用外部模型。
- 局域网入口：HTTPS `https://10.30.0.24:8484/?mode=session`，端口 8484，前端监听 `0.0.0.0`。截图位于被忽略的 `.dev-runtime/session-interactions/`。
