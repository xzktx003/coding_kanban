# 设计记录与本地产物

本目录保留已讨论的设计决策、行为边界和文字验收记录。正式产品行为以 `docs/session-*.md` 为准，旧评审稿用于解释设计取舍。

截图、可点击 HTML/CSS/JS 预览、检查脚本的生成 JSON，以及 `*.local.md`、`*.draft.md`、`tmp/` 下的临时文件只留在本机，由根目录 `.gitignore` 排除。文字记录中提及的本地产物不表示它们会随 Git 仓库发布。

可复现的回归测试保留在 `tests/e2e/` 和各模块单测中；运行日志与浏览器证据默认写入已忽略的 `.dev-runtime/`。产品图标和 README 正式配图不属于本目录的忽略范围。
