# 输入区悬浮提示栏

桌面附着条此前参与输入区正常布局。运行变更、待回答问题、排队消息或 Goal 出现和消失时会改变正文视口高度；隔离浏览器中仅显示一条运行变更，就观察到正文视口缩短约 19px。该证据说明一种布局抖动机制，不代表排除了现场的其他原因。

公共 Codex 输入区现在将上述条目、原生队列设置提示和发送结果提示放在输入区上方同一绝对定位层中。面板背景持续半透明，文字与按钮保持不透明；桌面最多 200px / 28dvh、手机最多 160px / 25dvh，长内容在面板内滚动。状态文字与重新核对按钮位于同一浮层的独立行；空白区域不拦截正文指针。提问弹窗仍在浮层之上，条目退出或收起时不可交互，关联队列菜单和确认面板关闭。

收起状态只在当前页面内按精确草稿 owner 区分，不写入会话数据或设备偏好；默认展开，切换回来保留，当前界面观察到所有条目消失后重置。为避免无界留存，最多记住 100 个收起的 owner。收起后保留展开入口、状态及发送结果摘要；页面重新加载恢复默认。问题自动打开、输入目标、草稿、任务和发送行为仍走原有路径。

入口靠近右侧状态文字：展开时仅显示无边框小图标，悬停或键盘聚焦时显示背景；收起后以小图标和“展开”保留明确入口。触屏使用更大的透明点击区域，不增加常显边框。

原生官方组件采用附着布局；本次根据用户要求有意改变外层定位和背景，不以几何完全相同作为验收条件，原生行内容与交互仍单独对照。原附着设计及历史验收记录保留在 [附着条记录](composer-attached-rail-20261027.md)。
