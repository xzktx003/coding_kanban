# 会话设置的多页持久化与发送边界

本轮修复针对[已确认的多页覆盖](thread-settings-multitab-audit-20261027.md)，范围是同源、同浏览器的设备本地设置。不同设备的草稿和选择仍独立；本地事务不赋予原生线程写入权，也不提供跨原生客户端 CAS。

## 实现与验收要求

原整份 `threads` localStorage 写入会让其他页的旧会话快照覆盖当前选择。修复采用每会话一行的 IndexedDB 事务，应用本机编辑、原生观察、精确回执及提示关闭的实际意图。旧全量键只作迁移备份，不再由新页面回写。设置分组、pendingFields、原生来源和仅补缺规则保持；权限观察元数据不落盘。

UI 继续同步显示用户选择，持久化在后台进行。恢复和保存失败有可见状态及显式重试；失败时保留输入和选择。历史读取在请求开始捕获设置身份，迟到响应不能覆盖请求后编辑；运行连接或账号通知撤销旧观察的身份。

主 composer 点击发送时捕获具体会话和配置，等待点击时已在保存队列中的意图完成并核对原运行身份，然后沿原发送路径提交。之后切换模型或输入目标不取消已捕获参数；失败的旧捕获仍失败，显式重试后的新捕获等待新的保存尝试。普通侧聊的默认参数使用同一边界。已经冻结的子 Agent 原生参数、回滚重发参数及新聊天创建配置保持各自来源，不能在等待之后用当前主会话设置替换。失败明确归类为尚未发出，不制造未知送达回执，不自动重发。

## 红灯与验收进度

真实浏览器旧实现已有6项失败、1项权限隔离控制通过，覆盖跨会话change/hydrate、同会话不同字段、迟到snapshot、ABA同值变化、initialOnly；日志位于 `.dev-runtime/session-thread-settings-multitab-20261027/`。新增服务边界测试先4失败／1通过，再5项通过，覆盖保存失败不写出、等待保存期间切换目标、显式子 Agent 参数独立。这5项控制持久层返回时机，只证明服务接线，不能替代真实IDB和完整composer验收。

实现和最终联合验收已完成本批范围；582文件3563项、57项浏览器及构建通过，1长期用例默认跳过，完整失败记录与未闭合目标见[第四批](session-parity-batch-r4-20261027.md)。正式访问为 **HTTPS https://10.30.0.24:8484（端口8484）**，测试写入均应由隔离fixture接收。不得为此重启正式运行层或 Agent。


## 事务边界

每行包含串行号、各设置组UUID身份及最多64条已处理意图标记；本页最多接受64个尚未保存的意图，达到上限明确拒绝本次修改并显示错误。读/原生ACK检查完整捕获身份，采取保守拒绝，不用墙钟时间推导原生新旧。open/read/write各10秒有界，事务超时撤销自有事务，迟到open关闭自有连接。旧备份只读迁移一次，空行同样遮蔽过时备份；权限元数据不迁移。

发送捕获只在WeakMap持有保存结果，不建立无限强引用捕获历史。HMR交接实际队列/事务和有限未保存意图，新调用与旧setter都走新reducer；旧代观察不能授予新代状态。HTTP LAN使用项目已有UUID实现，避免依赖仅安全上下文提供的`crypto.randomUUID`。这些边界已经纳入第四批最终组合门禁；仍不能把本机/模拟视口验收称为实体手机或所有终端完成。

消费者额外修复及真实Goal验证见[账号/运行代次与冻结参数](thread-settings-consumers-scope-20261027.md)。全局排队/Enter/审查偏好独立按字段保存，见[偏好多页修复](followup-preferences-multitab-20261027.md)。


### 冻结期间的补充只读审查

两个实际IDB控制器及第三恢复控制器已排除“先排队dismiss、后edit提交改号丢失关闭”的猜测：同一UUID的notice数字id从2变3，关闭仍保存。另测到公共API的延后调用边界：捕获id2/UUID后，等待提交改为id3才调用dismiss，入口仍按旧数字id拒绝，尽管UUID相同。当前唯一UI消费者同步claim，尚未证明界面可触发这个延迟路径；不要夸成已观察到用户故障。仅诊断、未改冻结产品，证据 `.dev-runtime/thread-settings-notice-race-20261027/`，后续应保持精确新旧notice隔离再处理该API边界。

上述延迟API边界在下一批已修复：有UUID按同一身份认领，没有UUID仍保留数字围栏；精确旧/新通知隔离及持久化回归见[关闭身份修复](notice-identity-dismiss-20261027.md)。原诊断与同步UI未见故障的边界保留。
