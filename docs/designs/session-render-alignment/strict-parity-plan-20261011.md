# Codex 会话体验严格对齐：待评审计划

状态：待用户 review，尚未批准实施。本文件只记录计划，不修改产品行为。日期：2026-10-11。

## 已确认的范围

- 唯一参考为官方 VS Code Codex 扩展 `openai.chatgpt 26.51002.51308`。参考包：`third_party/openai.chatgpt-26.51002.51308-linux-x64.vsix`，SHA-256 为 `c5f534abf7dd1f08330483b5db6754001f2ad452096fc8e63925e597d3761373`。
- 覆盖会话模式的完整 Codex 体验：会话入口与历史导航、正文、输入、菜单、请求、子智能体、文件与变更、设置、账号与宿主功能，以及各类加载和失败状态。
- 看板项目管理与终端模式入口作为外层工作台保留。Claude/ACP 的现存数据与运行链路不属于本次 Codex 复刻的替换对象；多 Agent 的工作台入口与 Codex 内部菜单明确分开。
- 此计划修订旧 [复刻方案](plan.md) 中的自定义例外：公共输入区分离、手机固定高度、额外常驻工具、自由分屏/网格和部分快捷键行为，均不再默认保留在 Codex 区域。
- 以该版本在 VS Code 客户端实际启用的分支为准。共享包中的桌面端功能、关闭的功能和其他输入框变体不作为本次参考；依赖账号或宿主的功能仍在审查范围内。

## 目前已核实的差异

| 差异 | 当前证据 | 处理方向 |
| --- | --- | --- |
| 自定义子任务栏 | `AgentComposer` 挂载 `SubagentSummary`；family 存在时即使没有行也可能显示“进行中 0”和“查看子任务” | 从 Codex 输入区移除该独立汇总，按官方后台智能体区域的真实条件、文案和展开结构替换 |
| 同类信息两次汇总 | 主输入另挂载 `BackgroundAgentSummary` | 两套入口不能继续并存；现有新版组件也须与原包逐状态比较后决定复用或替换 |
| 输入区及布局例外 | `AgentView` 采用窗口组/网格/列表加底部公共输入；旧方案保留手机固定高度和直接工具 | Codex 使用参考客户端的会话布局、输入位置和操作入口；外层项目/终端入口保留 |
| 提示区是本项目自己的组合 | `Composer` 将后台智能体、运行变更、模式、问题、模型提醒和队列放入 `session-composer-floating` | 核对官方主 composer 的各插槽、出现条件、顺序及空间规则，替换自定义组合规则 |
| 仍有自定义编辑与工具路径 | `ComposerSheet`、`RichDraftEditor`、`DrawingEditor` 等存在于当前输入工作流 | 逐项查官方对应功能；无对应的 Codex 入口移除，已有用户草稿和附件完整保留 |
| Esc 不同 | 当前请求卡片主要折叠/收起；原包部分请求面板会 cancel，同步提问面板还存在中断或空回答分支 | 列为执行行为评审项，严格核对具体请求种类和所属会话，不把所有 Esc 统一改成中断 |

这些是本轮源码审查结果。旧验收中“原生对齐”及单个原组件通过的记录不能证明整个会话体验一致；已对齐组件继续复用，以本轮实际对照结果决定剩余修改。

## 实施顺序与交付物

### 1. 冻结完整参考与差异矩阵

运行未改动的官方组件/可用的隔离扩展宿主，记录入口、功能开关、原生数据、主题变量、字体、缩放、DPR和视口。完整宿主与模拟 provider 的证据分开标注。每项功能记录原生触发条件、可见内容、操作、请求参数、成功/失败和恢复行为。

建立逐项矩阵：已证一致、需替换、缺少实现、依赖宿主/账号、尚未验证。已有文件的 staged/unstaged/untracked 内容先建立清单，只修改本轮相关部分，不整体回退旧成果。

### 2. 优先替换输入框和上方信息区域

删除自定义子任务汇总和重复入口。队列、后台智能体、目标、运行变更、提问以及必要通知分别接入官方对应位置；计数、空集合、已完成项、未知状态和按钮条件直接取参考行为，不自定“全部完成就隐藏”一类规则。

对齐主输入框、附件与长粘贴、模型/强度/权限/Fast、语音、发送/停止、`+`、`@`、`$`、`/`、全部关联菜单与提示。采用官方在对应容器宽度和输入设备下的布局；旧固定高度与常驻快捷入口不再成为验收标准。移除入口不会删除用户已保存的内容；必要的数据兼容只在底层实现，不增加自定义工具面板。

### 3. 对齐会话结构、正文和辅助面板

覆盖新建、历史列表、搜索、会话切换、名称与会话菜单；Codex 内不保留原生参考没有的网格、多窗口拖拽或公共输入工作流。界面替换沿用真实会话身份和现有数据，既有布局数据可以保留作兼容，不用重建会话实现换布局。

逐项核对流式/完成回复、工具分组、公开摘要、代码与 Markdown、引用、计划、文件与 Diff、review、子智能体列表与详情、审批、同步/异步提问及 MCP 表单。已验证一致的组件复用；展开、选择、返回、焦点和滚动规则也属于对齐范围。

### 4. 对齐功能调用与状态流转

覆盖 queue/steer、编辑/重试/暂停/恢复、停止、历史编辑与恢复、fork、目标、review、权限与模型配置、技能/插件/MCP、账号与额度、云任务、IDE 文件/选区/打开 Diff、听写等实际启用功能。每个入口验证真实动作与原会话回执。

UI 对齐与后端语义变更分开审查。此计划不授权将新的界面挂载、导航、历史读取变成 resume、创建 Agent 或获取执行权。需要新增协议或改变权限/持久化规则时，先提交具体差异和影响；期间继续已获批准且不依赖该修改的部分。

### 5. 原生对照与防回归

每个行为变化先写失败用例再实现，验证成功、失败、请求进行中切换会话、迟到回包、重复操作与重连。用相同状态数据、主题、字体、视口、缩放和 DPR 比较官方组件与产品：截图/叠图、几何、图标、文字和真实键鼠操作，不能只检查相似的类名或 DOM 属性。

覆盖宽桌面、窄容器、手机纵横屏、深浅主题、中文 IME、键盘导航、Esc、焦点恢复和减少动态效果。原版本没有真实手机宿主时，区分窄栏行为与浏览器必需的键盘/安全区适配；原包没有的适配不记为“官方一致”，也不继续套用旧自定义手机设计。

保留并验证 [会话内存约定](../../session-memory-contract.md)：`view=chat` 传输前裁剪、事件驱动恢复、有界流式缓存、相同快照不通知和隐藏正文回收。工具/历史详情通过受控按需读取保持完整交互，不把完整工具输出重新塞进所有聊天 SSE。涉及这些路径时运行对应原生 HTTP/EventSource 与 heap/renderer RSS 回归；不放宽已有性能预算。

### 6. 独立审查与最终验收

相关单测、`pnpm check` 及受影响浏览器门禁通过；运行层修改同时执行 `session:check`、`session:test`、`session:clippy`。既有失败与新增失败分别记录，不能把旧测试批次当作新交付的结果。

完成后至少连续两轮独立审查没有新增高优先级问题，逐项核对参考矩阵、功能操作、截图、控制台、失败请求和数据归属。更新功能/概览/架构及 bug 记录，交付实际访问地址、官方对照截图、功能结果和剩余依赖。

## 执行行为的明确评审边界

下面几项可能改变已有执行行为，不能由样式替换顺带完成：

| 行为 | 原包已观察到的行为/计划核对 | 影响及限制 |
| --- | --- | --- |
| 请求面板 Esc | MCP 请求存在 cancel 回复；同步提问 dismiss 在 `replyWithEmptyResponseOnDismiss` 或匹配的 resolution 元数据存在时回复空 answers，否则走当前会话中断；普通菜单关闭与这些行为分开 | 可能取消原请求或结束当前轮次。先验证实际扩展启用的面板与标记，提交准确请求/线程/轮次影响后再改；异步问题不能套用同步问题分支 |
| 后台智能体“全部停止” | 官方 `canStopAll` 决定入口，作用范围由原生调用链决定 | 可能影响多个后代。核对范围、轮次和能力后提交具体方案，当前身份校验和未知轮次保护不因 UI 复刻放宽 |
| 队列与引导 | 原生队列显示送达不明、暂停、失败和即时引导；表面按钮不能替代真实投递规则 | 若与当前网关规则不同，逐项说明触发和投递对象后评审；保持最多一次提交，切会话不会改变已捕获目标 |
| 历史恢复与工作区操作 | 原生 restore、回滚、Git/worktree 操作的影响须分别核实 | 会话历史与文件回滚不是同一动作；具体修改范围须明确，不修改用户真实会话作验收 |

本次整体实施批准后，上述尚未明确的协议/权限/执行语义仍按用户此前的分项确认边界处理。若希望一并授权，需先补充这些分支的具体方案，不能仅凭“一模一样”推导未知的破坏性操作。

## 完成条件与运行保护

- 完整 Codex 体验的所有启用条目有对应实现和可复核验收，未验证条目不标完成。
- 官方专属的账号/云端/宿主能力通过真实接口验证；外部条件未满足时列出待验条目，不以本地替代流程认定一致。
- Codex 区域没有本轮发现的自定义重复栏及未声明界面/行为差异；仍存在的浏览器宿主差异单独说明。
- 两模式挂载、快捷键、样式/Portal隔离通过；会话身份、输入、附件、历史与后台运行无本次回归。
- 联调使用独立 `.env`、端口、`SESSION_DATA_HOME`，前端绑定 `0.0.0.0`，用实际 LAN 地址验收。危险动作只操作隔离测试对象。
- 产品改造不停止、不重启、不接管真实用户会话；不向其发送测试指令，不修改其他进程。构建与正式启用分别安排。
- 不提交、不推送、不发布，保留所有无关工作区改动。之前暂停的输入跳动专项不在本次计划评审期间恢复；后续在输入区对齐的回归中检查布局稳定性。

现有持续 UI/UX goal 已读取并与本计划兼容，不创建重复目标，不因此次范围修订提前标记 complete。工具报告其状态仍为 blocked；本文件不是完成证明，也不改变该状态。
