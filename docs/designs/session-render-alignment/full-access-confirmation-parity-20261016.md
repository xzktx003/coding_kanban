## 来源与范围

当前原版权限入口的普通 legacy／new 两条分支都打开 `permissions-mode-dropdown` 的 `Ht`，能力行使用 `Ut`。原框包含带三角警告图标的标题、说明、文件／终端／互联网与应用三类能力、普通风险说明，以及“了解更多”“取消”“确认”；没有角落关闭按钮。原 `Ht`／`Ut` 与当前实装对应函数逐字相同，完整原模态注册链为 `Gx → FGa → BGa → Kx`。

本项开始时，`AccessModePopover → useSessionActionConfirmation → ConfirmDialog` 只呈现一段说明，标题／确认按钮及默认角落关闭按钮也不同。只对齐普通 Code 确认内容与呈现，保留现有捕获 thread、设置 setter、取消／卸载、侧边隔离和 Plan 切换规则；共享通用 Dialog 的默认行为不因本项改变。Cyber、ChatGPT namespace、Work／账号及托管策略分支继续独立，不将普通文案冒充这些分支的完整复刻。

原版普通“了解更多”为 `button[type=button]`，经宿主外部打开桥接使用固定地址 `https://developers.openai.com/codex/concepts/sandboxing#how-you-control-it`；它不确认或关闭对话框。原表单提交先 `preventDefault`，再确认并关闭；取消及 `onOpenChange(false)` 只关闭。局部设置更新不等于原生权限写入，浏览器验收不得触达正式 Agent。

只读准备额外核对了现有 en／zh／ja／fr 四种语言的 44 条原文／默认消息，以及三角图标、终端／互联网深浅配色等六段精确图标来源。该准备阶段尚无非中文语言或图标的实际渲染结果；标题的三角图标不能用权限菜单的盾牌替代。
