# 侧边聊天底栏布局验收

2026-10-16，Round 13。隔离前端 **HTTP `http://10.30.0.24:48865/`**，绑定 `0.0.0.0`。本批只修改 `.session-side-chat` 下的 CSS；没有修改草稿、权限、事件、发送或身份核对逻辑。

## 根因和改动

侧边 form 自身是 compact-composer 容器，桌面上的侧栏也会命中窄容器规则。旧规则将帮助／状态放在 frame 底部的绝对定位 14px 条带；另一个原生输入区后代选择器把侧边 frame 固定为 124px，已被输入区、44px 控件、padding 和 gap 占满，没有留出帮助文字的空间。

仅在侧边 form 的直接 frame／body／toolbar 内覆写：frame 自动高度，输入区保留不收缩的 62px，toolbar 允许换行，meta 作为完整第二行恢复正常流。帮助文字保持轻量，状态使用全行宽度并允许长文字折行；告警颜色、role、核对按钮和所有交互处理保持原实现。按钮不缩小，不通过隐藏状态或裁剪错误使验收通过。

## 红绿灯

复用正常菜单创建侧边聊天的浏览器用例，保留上一轮全部权限归属、两边草稿和无发送断言；新增空闲、真实 store 驱动的长模型通知、身份待核对并伴随存储告警三种布局记录。身份元数据接口仍由本页 fixture 返回，不连接真实 native；没有点击发送／停止来制造状态。

初次测试的元数据路由遗漏 `?view=chat`，导致夹具原始主线程元数据覆盖身份测试输入、核对按钮消失；该接线失败单独保留。按 pathname 匹配后，在**未改 CSS** 时双屏宽均于 footer 几何断言失败，测得帮助行侵入控件区 **12px**。

同一正式几何断言在 CSS 修复后，1440px／390px **2 项通过、零跳过**：

| 状态               | 旧布局                             | 修复后                                          |
| ------------------ | ---------------------------------- | ----------------------------------------------- |
| 空闲               | frame 124px；帮助行侵入控件 12px   | frame 146px；footer 与控件间隔 4px              |
| 长模型通知         | 单行区域无法容纳长状态             | 状态折行；390px frame 242px、1440px frame 226px |
| 身份告警与核对按钮 | 14px footer 容纳不了 44px 核对按钮 | frame 190px；告警及按钮完整保留                 |

三种状态均无横向／纵向裁剪，输入区仍 62px，本批各阶段可见的底栏按钮高宽至少 44px；主输入框的宽高、display、padding 和 gap 不变。两例无页面／控制台错误，每例 17 个输入前后相同。这里的手机结果来自浏览器视口模拟，未声称实机访问验收。

测试、截图与逐阶段 DOM 几何在忽略目录 `.dev-runtime/session-polish-round2-20261016/round13-side-footer-*`，原静态级联审计和修复前 CSS／测试副本位于同前缀的 `menus/side-chat-footer-style-audit/`。本批不构成完整官方侧边宿主逐像素对照；此前 30 分钟长测仍属于其冻结版本。

主输入区／展开编辑回归初批为 4 过、2 失败：旧测试仍在状态面板寻找已迁移到输入区的 Goal 清除按钮，并使用旧“排队消息”名称。按当前原版对齐实现修正入口，保留且补强草稿、清除、排队状态和几何断言后，独立单批 **6 项通过，52.4 秒，零跳过**；产品 CSS 在两批间未变。前端／共享类型及生产构建通过（Vite 44.02 秒），现有 chunk／动态导入提示保留。最终机器核对为 `round13-side-footer-final-verification.json`：2835 源码、21 E2E、3 基础设施、72 shared 输入均未漂移。

独立只读复核再次查看两张截图，核对旧 CSS AST：仅七条侧边限定规则新增，原规则零语义变化（另有一处换行）。六阶段主 frame 指标与修复前逐值相同。验收仅覆盖这些阶段可见的按钮；侧边运行态 Stop 未挂载，也未点击核对按钮验证业务成功。独立报告位于忽略目录 `menus/side-chat-footer-independent-review/`，前缀同上。
