## 修复范围与行为

旧 Shell 摘要已去掉占位提示，但 `CommandActionItem` 的读取、搜索、列目录分支仍硬编码「详情未加载」，展开链路也没有真实读取输出。现在普通命令和三个探索分支共同使用 `ShellCommand`：保留原摘要和文件入口，通过独立箭头显式读取精确的 thread/turn/item/type。正常完成、失败、停止与未知输出分别显示真实状态；没有原生持久化输出时显示明确提示。

只读 reader 仅发送 `initialize`、`initialized`、`thread/read`，按完整 JSON 和身份验证选出目标项。命令复制保留完整正文并沿用现有 shell 包装规范化，输出复制保留原始 ANSI。关闭、隐藏模式/页面/正文、目标变更或运行服务恢复时，立即清空详情 ref、卸载正文并取消在途请求；返回后须显式重新加载。聊天 `view=chat` 的浏览器接收前裁剪、60 秒普通正文宽限期、序号/审批/回复/草稿保护均保留。架构与启动兼容边界见 [命令详情](../../session-command-details.md)。

本次只合入所需详情通道和消费者。仓库原有 Codex 宿主、其他 UI 与协议改动继续保留；没有提交或推送。详情通道由网关调用独立 reader，因此已有运行层可继续服务 Agent。
