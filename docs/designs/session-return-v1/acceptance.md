# 功能页返回导航与提交验收

当前实现为完整功能页配合常驻“返回会话”标题条；顶栏“聊天”独立承担返回操作，模式切换只切换会话/终端。四个功能页为定时任务、工具与技能、用量和设置。

页面导航以白名单 `view` 参数和浏览器历史表示，前进、后退、刷新共用当前页状态。已打开的会话和工具树保持挂载；返回时恢复可用焦点，手机避免自动弹出输入键盘。加载中或功能页错误不会移除返回入口。

需要显式保存的表单通过共享离开保护登记未保存和保存中状态；返回、子页切换与浏览器后退复用同一确认流程，保存完成后可离开。会话草稿保持独立持久化，不作为需要丢弃的表单处理。

验证入口：

- `services/sessionPageHistory.test.ts`、`components/settings/codex/ConfigSettings.navigation.test.tsx` 与 `components/layout/AppLayout.mounts.test.tsx` 覆盖历史、表单保护和挂载保留。
- `tests/e2e/session-return-navigation.spec.ts` 覆盖 320/390/768/1440px 返回、草稿和历史、加载失败及未保存/保存中的导航。
- `tests/e2e/session-mode.spec.ts` 检查模式隔离及设备本地项目选择、服务端共享项目目录和刷新恢复；账号状态由测试模拟，不依赖个人登录。

本次提交验收在独立副本、独立 Rust 数据目录和端口进行，浏览器访问 HTTPS 局域网入口 `https://10.30.0.24:60053`；该端口仅供验收，结束后清理，不作为用户启动配置。日志保存在被忽略的 `.dev-runtime/publish-review/`。没有发送真实 Agent 消息；手机检查是浏览器视口模拟。
