# 会话功能页返回导航：设计记录

当前代码已实现本方案，提交验收见 [acceptance.md](acceptance.md)。下文保留原始评审方案和实施约束。

## 已确认的问题

2026-10-08 在 HTTPS 局域网入口 `https://10.30.0.24:8484/?mode=session`、1440×900 浏览器检查四个按钮：

- 定时任务、工具与技能、用量：没有明确的返回会话按钮。
- 设置：有“返回应用”，位置和其他功能页不统一；移动版本源代码使用 `Back`。
- 四个页面都可以再次点击顶栏已经选中的“会话”模式文字回到聊天。当前 `SessionTopNavigation` 给模式切换附加了 `setView('agent')`，形成难以发现的隐含返回操作。
- `useLayoutStore.setView` 只修改 store；页面切换没有独立的浏览器导航记录。
- `AppLayout` 已保留打开过的 AgentView 和工具面板树，可沿用并补齐返回状态验收。

这次检查证实了导航入口可发现性问题；没有证实这四个页面均存在无法返回的运行时崩溃。

## 推荐设计

保留完整功能页，采用统一壳层。技能管理、定时任务和设置都有列表、表单或内部导航，需要足够的操作空间。视觉沿用现有深色、轻边框、紧凑布局，不增加依赖或替换全站设计系统。

### 桌面

1. 模式开关继续使用共享 `WorkbenchModeSwitch`，只负责会话/终端模式切换。
2. 页面导航增加独立的“聊天”，与定时任务、工具与技能、用量、设置并列；高亮表示当前页面。
3. 四个功能页顶部共用固定标题条：`← 返回会话 | 当前功能名称`。宽屏右侧可显示原项目/会话名称作为返回目标提示，长名称截断。
4. 标题条位于内容滚动容器和加载/错误区域之外，始终可操作。原设置页重复的“返回应用”合并到此处。
5. 会话页保持现有项目列表、关注标签、分屏及输入区；额外的功能页标题条只在功能页出现。

### 手机及窄屏

1. 全局模式切换与状态继续保留，低频入口继续从更多菜单进入。
2. 功能页用 `← 返回会话 | 当前功能 ▾` 替换聊天标签区域；文字返回不折叠为仅图标，也不放进更多菜单。
3. 下拉可切换四个功能页，返回目标不随这类切换变化。
4. 按钮触控区域至少 44px，长标题收缩，页面不横向溢出。回到聊天后恢复原标签行。

## 交互约定

- 返回会话与点击“聊天”均恢复离开时的会话工作区，包括所选会话、项目、草稿/附件、阅读位置、分屏和已打开的工具。不创建新会话、不发送消息、不清空草稿。
- 如果用户从运行/待处理列表显式选择另一个会话，以这次选择为准，直接进入相应会话；不强制拉回旧目标。
- 如果原会话已被明确关闭或删除，返回当前仍打开的会话或聊天空态；不自动复活已关闭标签。
- 终端模式与会话模式保留各自挂载状态和位置；切回会话模式保留其页面状态。返回聊天使用明确入口。
- 页面前进/后退有可预期的 URL/history 语义；页面名使用白名单，保留现有 mode 参数。刷新功能页后仍有明确返回入口，直接打开功能页且没有选中会话时回到聊天空态。
- 键盘 Tab 可到达返回按钮。进入功能页聚焦页面标题；返回后优先恢复仍存在的离开前焦点，否则聚焦当前会话标签。不自动将焦点塞进输入框以免手机键盘突然弹出。
- 页面内对话框优先管理自己的 Esc 和焦点，本轮不增加全局 Esc 返回快捷键。
- 已明确使用“保存”的表单，离开前有未保存内容时统一提示“继续编辑 / 放弃更改”；保存中的表单应先等待结果。既有自动保存设置不增加重复确认。实施前逐页确认现有表单的保存方式。
- 功能页加载失败、请求慢、断网不阻断返回。隐藏页面不处理全局快捷键；VS Code iframe、工具终端及 Agent 生命周期遵守现有约定。

## 评审通过后的实施计划

1. 先补失败用例：四个入口都能明确返回；加载中/错误时可返回；刷新、前进/后退；长标题及 320/390/768/1440px；原会话、草稿、滚动、分屏和工具状态不变。
2. 在 `SessionTopNavigation`、`AppLayout` 附近增加统一页面导航/返回壳层；调整设置页重复返回按钮，沿用共享模式开关及会话选择动作。
3. 接入统一页面历史、返回状态及现有表单的离开保护，确保隐藏视图的焦点和快捷键隔离。
4. 执行相关单测、前端类型检查和隔离浏览器回归；核对会话/终端/VS Code 保活与无 Agent 副作用。更新 `docs/debug_list.md`、`docs/func_list.md` 及导航行为文档；如改变使用方式，同步产品概览。

最终实现采用“完整功能页 + 常驻返回会话”，桌面增加独立“聊天”入口，手机保留文字返回条。
