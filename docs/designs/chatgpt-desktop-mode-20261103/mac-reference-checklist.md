# Mac 原版：待执行的参考取证清单

此清单用于补齐静态代码不能回答的用户可见行为，**当前均未实测**。用户表示后续可能使用具屏幕访问能力的 ChatGPT 桌面端协助开发；目前尚未接入 Mac，具体取证环境待确定。先核对运行的 `ChatGPT.app` 与本次原包版本 `26.1027.61615 / 24141` 一致，记录 macOS、屏幕尺寸、缩放、语言、主题、账号类型和组织策略等与界面有关的条件；不收集或输出访问令牌、私钥、私人消息和用户工作目录内容。

使用全新隔离测试项目、可识别的测试会话及独立截图输出。只观察已有状态；创建任务、连接远程机、写入文件、改变云配置或执行其他具有副作用的步骤，必须在隔离对象中按用户同意的方式执行。不能关闭、停止、归档或接管真实工作任务。运行实例和工作目录身份不明确时，该项保持未验证。

## 逐场景记录

每一项记录：入口及可见条件、操作前状态、用户手势、状态与实际结果、涉及的主机/项目/会话、错误/取消/恢复、截图或短录屏及时间；依账号、平台或组织策略不可用时记录真实原因。截图需分开浅色／深色，并记录视口与显示缩放。

1. **整体框架：**应用顶部、侧边栏、项目区、聊天区、右侧内容和空态；项目分组、连接分组、单列表、侧栏宽度/折叠和快捷键。
2. **项目与主机：**本机与 SSH 项目添加、选择、移动、移除、目录不存在、同名项目和同路径不同主机；主机连接、离线、重连、认证提示，以及该操作影响的真实对象。
3. **会话：**新建、历史、分页、搜索、重命名、置顶、已读/未读、分叉和归档；运行中、待审批、后台完成及不同账号/执行域的显示。
4. **输入：**模型、推理强度、权限菜单、组织策略不可用项、文字与附件、发送/排队/steer/停止、排队暂停后的操作、Goal、计划模式及草稿恢复。
5. **正文与请求：**普通回复、流式过程、工具调用、错误、需要用户回答、单次/会话授权、自动审核、文件引用、工件和历史读取失败；确认每个动作的 owner 及回执。
6. **原版工作区布局：**截图右上角入口的实际动作；聊天旁内容标签、full/split 状态、侧聊创建/关闭和数据生命周期。另行记录本产品要求的多主会话自由分屏，它不由原版“内容标签分栏”自动证明。
7. **代码与工具：**本地和云来源的 Diff、stage/unstage、文件预览、终端、内置浏览器、站点工具、下载和复制；不同操作的只读与写入边界。
8. **附加页面：**设置、模型/账号、通知、快捷键、插件、技能、MCP、子 Agent、自动化及云环境；记录平台、套餐、组织权限或 feature flag 所致的可见性差异。
9. **云：**隔离环境下的环境列表/详情、仓库、镜像、脚本、网络、变量/密钥入口、创建和恢复任务；记录是否有实际服务权限和明确执行回执，不展示密钥值。
10. **跨端与平台：**SSH 连接与官方设备 Remote Control 分别记录；系统通知、文件对话框、窗口和内置浏览器能力与 Web 可实现边界分别核对。

## 输出与判定

- 逐项与 [54 条静态候选](original-static-features.md) 和后续新增候选建立映射；每项区分原包静态、原版动态、当前会话源码、第四模式实现、真实协议和 UI 验收。
- 原版功能不可达或账号无权限时，保留具体原因和截图；不能将静态存在视为用户可用，也不能把无法验证的功能标为不存在。
- Mac 原版动态取证通过不代表第四模式通过；第四模式必须在相同场景单独执行和记录对照结果。
