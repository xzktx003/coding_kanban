## 十项验收

| 编号 | 能力 | 验收证据 |
|---|---|---|
| 1 | 展开编辑 | 正文和代码模式切换后内容保留；收起、刷新与浏览器返回均覆盖 |
| 2 | 长文本折叠 | 大段粘贴仅生成一次上下文，不重复插入正文；队列与运行层请求包含完整日志；还原保留原正文 |
| 3 | 选区引用 | 浏览器真实 Range 选中“状态恢复”；提交快照准确包含该选区，刷新后保留 |
| 4 | 图片标注 | 原始 200×160 图像的边角 RGBA 保持 `[51,102,153,255]`，笔画区域像素变化；文字批注预览/导出共用换行规则；刷新后可再编辑 |
| 5 | 撤销 | 队列删除恢复顺序、参数与上下文；编辑撤销在弹层焦点范围内可访问；图片移除恢复可编辑标注；已送达/后续编辑/跨 thread 撤销被拒绝 |
| 6 | 文件上下文 | `@` 选择后显示快照；源文件变化不会静默更新，明确点击后替换；编辑器选区保留路径和行号 |
| 7 | 代码编辑 | fenced code block 高亮与语言选择；纯文本往返、缩进/换行、未闭合围栏和嵌套围栏回归 |
| 8 | 快捷命令 | `/plan`、`/effort` 操作保留当前草稿，不启动原生轮次；列表可搜索，模型面板复用真实支持档位 |
| 9 | 画草图 | 实际鼠标落笔、撤销/重做、返回恢复；导出上传载荷中验证 PNG 魔数；触点捏合到 200% 且不留意外笔画 |
| 10 | 配置快照 | 明确显示入队时模型/强度/权限/模式/目录/附件；删除撤销与原生投递均保持原配置 |

## 手机与桌面

- 320、360、375、390、430、768、1440px 截图检查；手机主工具按钮高度不低于 44px，模型与 High 文字可见，页面不横向溢出。
- 触屏浏览器回车保留换行、不提交；390px 触点事件验证双指缩放。844×390 横屏保留发送入口。
- 模拟 `visualViewport.height = 500` 后输入区上移，发送按钮底边不超过 500px；完整截图下方空区代表键盘占用区域，没有伪造系统键盘。
- 全屏画板和详情面板的四边都在可视区域内；嵌套附件详情返回后大编辑器仍保留，下一次返回才退出编辑器。
- 桌面沿用单行工具栏与侧边聊天；停止/排队/引导、代码审查、未知回执重试身份、迟到响应和跨会话草稿保护均做回归。

## 红绿灯与自查修复

先增加内容模型、草稿所有权、服务端撤销失败用例，再实现；后续浏览器/边界失败用例驱动修复：

1. Lexical 在 React 捕获阶段已生成文本卡片后仍执行默认粘贴，造成重复正文；阻止默认行为并终止传播后验证正文不变。
2. Tailwind 的独立 translate 未随 transform 清除，手机弹层越出屏幕；单独清除 translate，补充四边断言。
3. 原图按宽度放大后画布超出编辑视口；按可视高度与原图比例共同约束初始大小，触点映射保持相同坐标系。
4. 标注换行在 SVG 预览与 Canvas 导出不一致；共用文字布局、编号批注和边界检查。
5. 围栏内输入同类围栏会切断代码块；动态加长外层围栏。只有引用的消息回显为空；回显和原生投递统一上下文序列化。
6. 存储恢复覆盖旧快照、附件撤销抓取旧 render 状态；改为合并恢复和操作时读取最新快照，写入失败阻止发送。
7. 全局撤销按钮在模态框外不可通过焦点导航访问；提示移入活动模态框，并在关闭后回到 Session 范围。

全仓复查同时同步了已有测试的接口边界：审批断言包含原请求身份；可重试拒绝与送达不明的网络错误分开验证；离线项目操作从独立持久日志读取；移除 Testing Library 不支持的 `exact` 选项。未更改这些功能的运行逻辑。
