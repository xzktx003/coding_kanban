## 十项能力如何进入界面

| 编号 | 能力 | 电脑端入口与表现 | 手机端入口与表现 |
|---|---|---|---|
| 1 | 展开/收起输入框 | 输入框展开图标；进入工作区内的大编辑视图，可返回草稿 | 独立全屏编辑；顶部返回，底部保留模型/强度、停止与发送 |
| 2 | 长文本粘贴折叠 | 文本卡片显示名称、行数；点击预览，可还原到正文 | 卡片摘要；底部面板查看全文；还原进入大编辑视图 |
| 3 | 选区引用追问 | 回答选区上方出现“引用到输入框/侧边追问” | 使用系统文本选择，稳定后提供引用入口；可用消息菜单“引用”作为替代 |
| 4 | 图片标注 | 图片卡片 → 标注；画笔、箭头、矩形、文字与批注 | 全屏画布；44px 工具，显式绘图/移动模式，双指平移缩放 |
| 5 | 附件与队列撤销 | 删除后反馈条提供撤销；队列编辑也可撤销 | 反馈条置于键盘上方，不遮发送；读屏提示，不依赖快捷键 |
| 6 | 文件上下文卡片 | `@文件` 后生成卡片；查看路径、行号、实际引用文本 | 默认两张摘要卡片 + “查看全部 N 项”，完整列表在底部面板 |
| 7 | 代码编辑 | 代码块语言选择、高亮；支持纯文本切换 | 大编辑视图里编辑代码；长行内部滚动，语言选择用面板 |
| 8 | 快捷命令补全 | `/` 搜索；模型、思考强度、规划与现有命令统一入口 | 输入 `/` 或 `+ → 快捷命令`；列表适应可视高度，单层导航 |
| 9 | 输入栏画草图 | `+ → 画草图`；与标注共用工具；完成后附加 | 全屏画布；工具固定在画布之外，操作不依赖 hover |
| 10 | 队列配置快照 | 队列条展开后显示原模型/强度/权限/模式/附件/项目 | 底部队列面板展示同样信息；当前设置与入队时设置明确区分 |

## 三层信息与发送规则

1. 对话正文：任务进展与回答；停止之后保留已有内容。
2. 输入区上沿：有队列时显示下一条预览和总数；不会始终展开所有任务。
3. 输入容器：附件/引用摘要、正文、设置与动作。无附件时整行自然消失。

桌面底栏一行：添加、权限、展开；右侧模型/思考强度、语音、停止和主动作。输入宽度不足时采用手机式分行，不缩小字体或隐藏思考强度。

手机两行底栏：第一行是“权限”和“Codex · Astra · High”；第二行是添加、展开、语音、停止和发送。这样不再争夺同一行宽度。长模型名可截短，完整名称可在选择面板查看；Agent 与思考强度不得截没。

| 状态 | 主动作 | 说明 |
|---|---|---|
| 空闲、无草稿 | 禁用发送 | 附件也计入有效草稿 |
| 空闲、有草稿 | 发送 | 接收确认后才清除本次草稿 |
| 运行中、无草稿 | 停止 | 不显示多余的禁用排队按钮 |
| 运行中、有草稿 | 排队或引导，沿用用户偏好 | 停止保持独立；两者不能使用同一种含糊图标 |
| 队列暂停 | 队列条显示暂停与继续 | 新入队不隐式恢复队列 |
| 离线/状态不明 | 原位说明 | 保留草稿，无法确认是否投递时禁止盲目重复发送 |

停止并发送保留在 `+ → 发送方式`，清楚写出完整动作。等待停止回执之后才发送新草稿；旧队列保持暂停。

桌面沿用现有 Enter/组合键偏好，并保护中文输入法组合态。本稿建议手机软键盘 Return 换行，通过可见按钮发送；外接物理键盘沿用用户桌面偏好。此项是待评审的交互决定。

## 手机适配细则

- 覆盖 320/360/375/390/430px 竖屏，横屏、平板与窄桌面另作布局验收；页面不能横向溢出。
- 输入正文字号至少 16px，主触控目标至少 44×44px；文字辅助信息不承担唯一操作入口。
- 键盘出现时使用实际可视视口高度，考虑地址栏和安全区域；输入区保持在键盘上方。队列压成单行，附件压成摘要，正文限制高度后内部滚动。
- 极矮横屏先收起队列预览和附件明细，保留数量入口、模型/强度、权限与发送；必要时提示进入全屏编辑，不能靠把按钮缩小来塞入。
- 上下文、模型、命令、队列使用底部面板，受键盘上沿约束。面板需要输入时，搜索框与当前编辑字段保持可见。
- 展开编辑、图片标注与画板使用全屏视图。返回保留草稿；图片编辑返回保留临时标注，再次打开继续。放弃修改使用单独显式入口。
- 面板关闭恢复原焦点与阅读位置；系统返回先退出面板，不直接退出会话；触屏无 hover 依赖。
- 手机文字选区保留原生手柄及复制操作，不能通过全局 touch 处理破坏选词；选区浮条不能与系统菜单叠在同一位置。
- 侧边追问在手机上进入带“返回主会话”的独立视图；主、侧草稿分别保存。
- 图片标注支持触摸、鼠标、笔。单指绘图/双指缩放只在绘图模式生效；切到移动模式后单指平移，避免缩放时误落笔。

## 内容与误操作边界

- 文本折叠只改变显示，不丢弃字符；建议初始阈值为超过 2,000 字符或 40 行的单次粘贴，最终阈值待评审。始终提供还原入口；还原在原光标处插入，不覆盖已有文字。
- 引用与文件卡片需保存可追溯来源、范围和快照。整文件引用与选区引用要区分；源文件后续变化时给出更新提示，不能悄悄改变已排队消息。
- 高亮编辑与纯文本来回切换保持代码内容、缩进和换行；不把展示用 HTML 发给 Agent。
- 图片标注与草图先进入附件草稿，再随消息提交。保留原始图片和可编辑标注，取消不修改原图。
- 队列编辑保留该消息的模型、思考强度、权限与附件；当前输入栏设置仅作用于新提交。只读显示配置快照，不在本轮顺带增加队列换模型功能。
- 撤销只作用于仍可修改的未发送消息；如果状态已变化，明确说明不能恢复或需作为新草稿恢复，不重复投递。删除、恢复等异步返回限定在原会话。
- 提议撤销提示默认显示 8 秒；键盘焦点或指针停留时不自动关闭。手机键盘出现时反馈跟随可视区域，不覆盖主动作。
- 草稿按现有 Agent/session 范围隔离，附加引用、长文本、标注编辑状态也纳入恢复。这里只承诺本设备持久保存，不暗示跨设备同步。
