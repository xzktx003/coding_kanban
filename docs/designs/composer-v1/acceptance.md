# 输入区改造与验收

2026-10-08。实现已按用户确认的深色草图完成；用户随后要求思考强度常驻显示，入口调整为桌面 `Codex · Astra · High`，手机在同一按钮中分两行显示。`None` 也明确展示，不用无提示的空白代替。

局域网入口：[HTTPS 会话工作台，端口 8484](https://10.30.0.24:8484/?mode=session)。地址取自本次环境，未写入产品源码。前端继续绑定 `0.0.0.0`，本次不重启 Rust runtime，不对已有 Agent 发消息或中断。

## 实现

- `session-composer.css` 单独承载新样式，限定 `.session-mode`，沿用主题变量；统一圆角输入面，无内部工具栏分隔线。
- 输入目标分成项目与会话名，两者独立省略，避免长项目名吞掉实际发送目标。
- 运行中无草稿仅保留停止；有草稿时增加排队/引导主按钮。停止并发送和临时发送方式进入加号菜单；审查入口在同一菜单，侧边聊天入口在会话更多菜单。
- 队列贴在输入框上沿，一条默认预览，多条按需展开；编辑、排序、暂停、清空在消息菜单。手机删除进入菜单，暂停仍明确展示原因和继续入口。
- Agent、模型、思考强度与权限保持可见。手机省略权限旁的装饰图标，保留权限文字；思考强度使用同一选择器中的第二行，语音不移除、不额外创建第二个录音实例。
- Plan/Goal 有独立紧凑状态行，取消模式不会提交正文；侧边聊天输入独立，手机全屏展示，返回主会话恢复主输入焦点。
