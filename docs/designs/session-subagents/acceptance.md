# 子 Agent 实施与验收

日期：2026-10-08。批准方案已实现。工作区同时有其他 AI 的状态恢复、队列和导航改动；本次保留这些改动，子任务只扩展引用负载与停止入口，不重写队列调度。未提交或推送，未修改用户登录配置。初次代码验收未重启正式服务；随后按用户明确的中断授权完成运行层激活，见文末补验。

## 实际入口与环境

隔离前端验收使用 **HTTPS `https://10.30.0.24:5173/?mode=session`**，监听 `0.0.0.0:5173`，由真实 LAN 地址访问 Chromium，包含 390px 手机、320–1440px 输入区与深浅主题。HTTPS 提供浏览器草稿提交所需的安全上下文。测试 API 为隔离浏览器夹具；原生 RPC 另外在 loopback HTTP、独立端口与数据目录验证，不能把浏览器夹具称为真实模型执行。

原生脚本创建独立 `CODEX_HOME`、`SESSION_DATA_HOME` 与 Claude 数据目录，本地确定性 Responses/SSE 模型服务，实际启动两个原生子线程；远程模型请求为 0。退出只停止自己的进程。浏览器测试记录 pageerror 和非预期 console error，原型预览不作为产品验收证据。

初次代码验收时，`pnpm session:status` 确认正式会话服务仍运行旧二进制：磁盘构建与活动进程不同。新运行层的 metadata/roles、输入权前校验与 RPC 回复实例保护已编译并在隔离原生环境通过；当时正式运行层尚未激活这些变更。已有只读端点可提供元数据/角色兼容回退。完整原生保护须在活跃 Agent 的安全窗口启用新二进制。

## 红绿灯中发现并修复的问题

- 缓存 revision 会压住新查询，缓存输入权与状态会误作为当前事实：恢复时清空执行权限与版本，晚到快照按实时 revision 保护。
- 不可用历史仍显示旧“运行中”：保留身份，标未知并撤销能力。
- 本轮停止误包含其他轮运行任务：范围函数独立验证，本轮只含确认的创建轮次。
- 检查返回时历史任务被默认范围隐藏：恢复正确范围与焦点。
- 子提交误认为旧队列失败属于新输入，或借用父输入的模型/权限：精确提交回执确认，子元数据/原生继承，独立版本和共同提交锁。
- 运行实例复用原生 request ID：增加非凭证关联标记并在运行层原子核对真实待处理集合。
- 新增 @ 容器破坏附件按钮 first-child 样式：按首个直接 button 匹配，引用入口补足 44px。

另更新两份旧浏览器夹具：执行权核对使用当前分页只读同步入口和新提示文案；VS Code 项目切换等待实际 setCurrentThread(null)，取消旧历史加载。仍断言无 resume/start/interrupt、原草稿保留、项目跟随与 iframe 身份不变，没有通过放宽这些行为断言隐藏失败。
