2026-10-08。最终采用用户追加要求：图片在正文左侧；展开编辑、语音、输入状态和会话更多操作保持直接入口；上方的队列、引导与模型提示悬浮覆盖聊天区。

## 布局与行为

- 桌面框体 124px、整体输入区 132px；手机及窄分屏框体 140px、整体 148px。系统安全区另计。输入区使用当前窗口可用宽度，桌面上限 1280px，移动端左右 8px。
- 固定正文行和单行发送工具栏，会话/项目/Agent 信息位于底部中间；窄屏底部保留 14px 信息行。长文本在正文内部滚动。手机图片 84×62px、桌面 68×68px；多图横向滚动，图片区最大占正文行宽度的 40% / 35%。单张图片不再展示占宽的“1 项”按钮，点击图片即打开详情。
- 展开编辑、语音、状态与会话更多操作直接可见。桌面放在工具栏，窄屏放在上沿的悬浮工具条；加号保留原来的附件、上下文和工具功能。Agent、模型、思考强度、权限、发送和运行中的停止保持可见。
- 队列继续使用原来的单行首条预览、立即引导与删除/更多；点击预览可展开配置。队列预览约 50px 高，背景 78% 不透明、3px 背景模糊；队列与模型通知绝对定位在输入栏上方，遮盖部分聊天内容，不参与布局高度。手机删除沿用更多菜单，完整队列面板保留直接删除。
- 阻断错误仍然阻断发送。错误摘要显示在固定信息行，完整错误及重试在直接可访问的状态/附件面板中。规划与目标操作在状态面板保留。
- 异步答题面板覆盖输入区，普通输入节点保留并设为 inert；收起恢复原草稿。新问题自动展开、旧轮问题不提醒、跨窗口/设备答题与原协议一致。
- 侧边聊天使用自身 thread 的模型设置；展开编辑关闭后显式恢复编辑器焦点和选区。Claude/ACP 复用固定框体与左侧图片预览，保留原发送、权限及显式下载安装行为。
