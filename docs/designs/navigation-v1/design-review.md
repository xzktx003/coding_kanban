## 当前问题的代码依据

- `session-interactions.css` 中 `.session-nav-row:has(> .session-nav-title)` 强制纵排；标题最多两行，meta 至少 24px，叠加 padding 后，每条占用明显偏大。
- `.session-row-title` 为 14px / 500；多数标题都是主色，缺少普通行与当前行的区别。
- `ThreadList.tsx` 的 meta 同时放 Agent、时间、重命名、归档。按钮 opacity 为 0 时仍占布局位置，时间也不能真正靠近最右端。
- `SideBarProjectList.tsx` 主要靠较小间距分组，未形成清晰的分组边界。
- “加载更多”沿用通用按钮，没有侧栏专用的字号、行高和对齐规则。
- `ProjectNavigationButton.tsx` 总是显示项目名、斜杠、“会话”、定位按钮；已有标签与模式切换后，重复的“会话”不提供新的定位信息。
- `AgentViewHeader` 和 `SessionTabs` 各占一行。只删除两个字能省横向宽度，合并才会省纵向空间。

## 侧栏设计

| 元素 | 拟定规则 | 原因 |
| --- | --- | --- |
| 宽度 | 默认 288px，未来沿用现有侧栏宽度机制 | 稳定的扫描列，不把边栏做成内容卡片 |
| 顶部 | 44px 一行：收起、搜索、新会话 | 删除“项目与会话”大标题，减少重复 |
| 分组工具 | 项目 + 筛选/历史/添加，12px 以下标签、14px 图标 | 高频动作保留，视觉弱于会话标题 |
| 项目名 | 12px / 550，文件夹 + 常显展开箭头 | 清楚表达父子关系和折叠能力 |
| 项目分隔 | 组间细线 + 约 12–14px 留白 | 可扫描边界；不为每条会话画线 |
| 会话行 | 桌面 36px；标题 13px / 400；默认单行 | 同屏更多会话，去除卡片感 |
| 长标题 | 省略号；hover/focus 展示完整名称、Agent、时间 | 不自动改名，不把聊天预览当会话名 |
| Agent | 左侧常显 14px 单色标识 | 不另占一行，不用彩色徽章；形状可辨 |
| 时间 | 行尾 11px 等宽数字，保持现有时间语义 | 本次不把创建时间悄悄改成更新时间 |
| 状态 | 时间前独立 12px 形状：运行环、待确认叹号、未知问号 | Agent 归属与运行状态分开，不只依赖颜色 |
| 操作 | hover / focus-within 后，行尾时间槽替换为“…” | 文字和标题不位移；菜单包含重命名、归档等 |
| 当前行 | 中等深度底色 + 左侧 2px 短标记 | 与普通 hover 区分；其他行不铺底、不加粗 |
| 分页 | 独立 28px 行，双下箭头；可切换“⌄⌄ + 更多”比较 | 与“…”操作菜单、单箭头折叠分开 |

分页 tooltip / aria-label 为“加载更多该项目的会话”；加载时禁用并显示反馈，失败必须有“加载失败，重试”文字，不让错误也只剩一个符号。无下一页时移除控件。原型演示成功路径，失败/空页/重复点击属于正式实现验收。

原型用仓库既有 OpenAI 单色图形指代 Codex，用仓库既有 Claude Code 图形指代 Claude Code，用 Plug 表示 ACP。正式稿优先确认 Codex 的专用单色标识；不把底色或品牌色当作识别手段。未知 ACP 保留名称可访问文本，详情中显示具体 Agent。

全称会保留在会话详情/Agent 菜单中；列表仅缩小表现。新提案响应本轮图标化要求，不受以前文字 badge 方案限制。

## 顶栏 A：合并，推荐

```text
[侧栏搜索 / 新建] │ [项目名 ▾] │ [Agent 会话标题 ×] [另一个标签]  + │ 布局 终端 编辑 …
                 │                     正文
```

- 原有 44px 项目栏 + 44px 标签栏，合为 44px，一次省下 44 CSS px。
- 全局模式切换仍保留，因此不必在项目后重复“/ 会话”。
- 项目名保留为紧凑菜单入口，最大宽度约 190px，不能完全删除：侧栏关闭及跨项目标签时仍需要上下文。
- 定位当前项目、复制完整路径等低频动作收进项目菜单。
- 切换已有标签后项目上下文跟随标签；点击项目入口不应隐式启动、审批或中断 Agent。
- 标签可以跨项目共存。项目切换不应把其他项目的关注标签过滤掉。重名标签应显示短项目后缀，完整路径可访问。
- 布局、终端、编辑面板入口保留在右侧；小宽度移入“…”溢出菜单，不能丢失能力。
- 网格/列表模式沿用 44px 项目工具栏，没有标签时不留下空占位；多窗口组的标签保留各组，合并针对 solo 标签模式。

## 顶栏 B：保留两层

```text
[项目名 ▾]                                  [布局 / 工具]
[Agent 会话标题 ×] [另一个标签] +
```

删除“/ 会话”、独立文件夹装饰和常驻定位按钮的冗余组合，项目收敛成一个菜单入口。
优点是标签多、工具多时空间稳定；缺点是仍占 88px。只希望小幅调整可选 B。

## 颜色与无障碍

采用现有冷灰方向，强调色沿用低饱和暖色；提议值在原型 CSS 中定义，未覆盖产品主题。

- 深色：侧栏 `#191e24`，正文 `#20252c`，当前行 `#303842`。
- 主文字 `#e5e9ee`，普通标题 `#b2bbc5`，辅助 `#9ba6b2`，分隔 `#38414c`。
- 普通标题与当前标题同时靠字色和底色区分；辅助文字保持可读，不以极低透明度消失。
- 每个 icon-only 按钮必须有 aria-label、tooltip 和可见键盘焦点。完整标题应支持键盘 focus 的信息浮层，不能只依靠原生 title。
- 桌面操作菜单 hover 与键盘 focus 都能触达；手机常显操作入口，文字时间退至详情，点击目标以 44px 为准。
- 窄屏采用项目抽屉，项目名允许压缩、工具溢出，标签区域独立横滚，不让整页横向溢出。
- 深浅色都保留层级与状态形状，减少动态效果。连接未知不能伪装为已完成或确定的零。
