# 会话窗口选中提示

自由分屏和网格多窗口共用蓝色内侧轮廓。深色使用更亮的蓝色，让当前输入窗口与普通分隔线清楚区分；标签与标题栏保留既有底色。选中标签保留 2px 下划线，浅色使用暖棕色、深色使用香槟金，避免把标签也染成蓝色。正文、运行/未读/待确认/失败标记沿用原规则。

| 提示             | 浅色主题       | 深色主题         |
| ---------------- | -------------- | ---------------- |
| 当前窗口轮廓     | `#3b82f6`      | `#60a5fa`        |
| 当前标签下划线   | `#94713d` 暖棕 | `#d6b77a` 香槟金 |
| 标题栏与标签底色 | 沿用原主题     | 沿用原主题       |

实现位于 `apps/web/src/session-mode/session-selection.css`，在既有导航样式之后加载。仅作用于 `.session-mode`，复用 `data-group-active`、`data-selected` 和 `data-active`，不增加选择或导航逻辑。网格只修改完整卡片的 `data-card-root`，不修改列表行。

## 保持几何稳定

- 外部边框保留固定宽度；选择只改变颜色。`outline: 2px` 配合 `outline-offset: -2px` 在内部绘制，不占布局空间。
- 下划线使用内侧阴影，不改变标签字号、字重、间距和高度。保留既有标签底色以及分屏激活组的普通标题栏背景。
- 窗口取消样式过渡，选中卡片的旧装饰环由蓝色轮廓替代。没有增加位移、缩放、节点替换或滚动操作。

## 验收

浏览器通过局域网 HTTPS 页面 `https://10.30.0.24:8484/?mode=session`，使用独立页面上下文与完整 API fixture；主机和端口没有写入产品源码。没有发送真实 Agent 消息或停止服务。

沿用 `tests/e2e/session-light-selection.spec.ts` 的文件名，内容扩展为两种主题、自由分屏/网格、900/1440px 共 8 个场景：

1. 先复现深色未采用清晰轮廓，再复现标签/标题栏被染蓝；修复后检查 2px 蓝色轮廓、主题分别对应的暖色下划线，以及原有背景。
2. 对当前窗口轮廓与主题背景要求至少 3:1 对比，标题文字与原标题背景至少 4.5:1。
3. 加载长历史并进入稳定阅读位置，每个场景连续选择 12 次；逐动画帧测量全部窗口、标题栏及分屏分隔条，要求最大变化为 0 CSS px，原节点保持连接。
4. 检查各窗口阅读位置与唯一选中状态；再切换深浅主题，确认轮廓更新、几何和阅读位置保持。

红灯日志：`.dev-runtime/selection-review-red.log` 与 `.dev-runtime/selection-review-border-only-red.log`。最终测试日志：`.dev-runtime/selection-review-border-only-green.log`。最终截图：`.dev-runtime/selection-review/{split,grid}-{900,1440}-{light,dark}.png`；旧效果和中间版本单独保留作比较。以上是本地生成产物，不提交图片。

本次为桌面/平板浏览器验收，不声称实体设备已验证。

最终结果：8 项浏览器用例通过，96 次窗口选择共审计 1,115 帧，最大几何变化为 0 CSS px；阅读位置、原节点和主题切换保持稳定。前端类型检查、生产构建与限定文件格式检查通过。构建日志为 `.dev-runtime/selection-review-build.log`。
