# 浅色会话窗口选中提示

自由分屏和网格多窗口在浅色模式下采用同一套选中提示：蓝色内侧轮廓、淡蓝标题栏；分屏的当前标签同时使用浅蓝底色及蓝色下划线。未选中窗口保留原有背景，正文保持原背景，运行/未读/待确认/失败标记沿用原规则。

实现位于 `apps/web/src/session-mode/session-selection.css`，在既有导航样式之后加载，以避免被普通分隔线样式覆盖。所有规则限定 `.session-mode.light`，不修改深色模式。选择状态复用 `data-group-active` 和 `data-selected`，没有增加新的选择或导航逻辑。

## 保持几何稳定

- 外部边框仍使用原有固定宽度；选中仅改变其颜色。
- 蓝色轮廓使用 `outline: 2px`、`outline-offset: -2px`，在窗口内部绘制，不占布局空间。
- 标题栏和标签只改变背景/下划线颜色，不改变字号、字重、间距和高度。
- 浅色窗口取消样式过渡，选中卡片的旧装饰环由蓝色轮廓替代；不增加位移、缩放、节点替换或滚动操作。
- 网格规则限定完整卡片的 `data-card-root`，不改变列表模式的选中行。

## 验收

浏览器用独立页面上下文及全量 API fixture 在局域网 HTTPS 入口运行；当前配置为 `https://10.30.0.24:8484/?mode=session`，源码不固定主机和端口。没有发送真实 Agent 消息或停止服务。

`tests/e2e/session-light-selection.spec.ts` 覆盖自由分屏与网格、900/1440px 两种宽度：

1. 对蓝色轮廓、2px 轮廓厚度及淡蓝标题栏做计算样式检查。旧样式首先触发失败用例。
2. 装载较长历史，进入阅读位置；待虚拟列表的首次行高测量稳定后开始审计，避免将初始化测量与选择混淆。
3. 每个场景连续选择窗口 12 次；逐个动画帧测量所有窗口、标题栏和分屏分隔条的 x/y/width/height，严格要求最大变化为 0 CSS px，并检查原节点仍然连接。
4. 比较切换前后的各窗口 scrollTop，检查唯一选中窗口，以及深色模式不使用新蓝色轮廓。

测试日志及逐帧汇总位于本机被忽略的 `.dev-runtime/light-selection/final-browser.log`；深浅色效果图位于同目录的 `split-{900,1440}-{light,dark}.png` 与 `grid-{900,1440}-{light,dark}.png`。前端类型检查和生产构建使用 `pnpm --filter web build`。本次为桌面/平板尺寸浏览器验收，未声称物理设备已验证。

最终结果：4 项浏览器用例通过，48 次窗口选择共审计 525 帧，最大几何偏差为 0 CSS px；各阅读位置保持、原节点未替换、深色恢复原样式。前端构建及限定文件格式检查通过。
